# ColdFusion コーディング標準

- 構文をわかりやすくするために、可能な場合は CFScript を使用してください。
- 非推奨のタグや関数の使用は避けてください。
- 変数とコンポーネントについては、一貫した命名規則に従ってください。
- SQL インジェクションを防ぐには `cfqueryparam` を使用します。
- ## を使用して <cfoutput> ブロック内の CSS ハッシュシンボルをエスケープします
- <cfoutput> ブロック内で HTMX を使用する場合は、意図しない変数補間を防ぐために、二重ハッシュ (##) を使用してハッシュ記号 (#) をエスケープします。
- HTMX ターゲットファイルにいる場合は、先頭行が <cfsetting showDebugOutput = "false"> になっていることを確認してください。

# 追加のベストプラクティス

- アプリケーションの設定とリクエストの処理には `Application.cfc` を使用します。
- 保守性を高めるために、コードを再利用可能な CFC (コンポーネント) に編成します。
- すべてのユーザー入力を検証し、サニタイズします。
- エラー処理とログ記録には `cftry`/`cfcatch` を使用します。
- ソースファイルに資格情報や機密データをハードコーディングしないでください。
- 一貫したインデントを使用します (世界標準に従って 2 つのスペース)。
- 複雑なロジックにコメントを付け、関数を目的とパラメーターとともに文書化します。
- 共有テンプレートには `cfinclude` を優先しますが、循環インクルードは避けてください。

- 可能な場合は三項演算子を使用してください
- 一貫したタブの配置を確保します。
