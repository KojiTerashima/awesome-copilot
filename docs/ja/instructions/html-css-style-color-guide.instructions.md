# HTML CSS スタイル カラーガイド

ブラウザー描画向けの HTML/CSS スタイルを更新または作成する際は、これらのガイドラインに従ってください。色名は、それぞれの色相範囲全体を表します (例: "blue" には navy や sky blue なども含みます)。

## 色の定義

- **暖色**: オレンジ、赤、黄
- **寒色**: 青、緑、紫
- **中立色**: グレーおよびグレースケールのバリエーション
- **二値色**: 黒と白
- **60-30-10 ルール**
  - **主色**: 60% 使用する (*寒色または明るい色*)
  - **副色**: 30% 使用する (*寒色または明るい色*)
  - **アクセント**: 10% 使用する (*補色関係にある暖色*)

## 色の使用ガイドライン

背景、ボタン、カードなどのグラフィック要素には、**60-30-10 ルール** を適用して色のバランスを取ってください。

### 背景色

**使用しないこと:**

- 紫やマゼンタ
- 赤、オレンジ、黄
- ピンク
- あらゆる暖色

**推奨:**

- 白またはオフホワイト
- 明るい寒色 (例: 薄い青、薄い緑)
- 控えめな中立トーン
- 色差の少ない淡いグラデーション

### 文字色

**使用しないこと:**

- 黄 (コントラストと可読性が低い)
- ピンク
- 明るい背景上の純白または淡色テキスト
- 暗い背景上の純黒または暗色テキスト

**推奨:**

- 暗い中立色 (例: #1f2328, #24292f)
- ほぼ黒のバリエーション (#000000 から #333333)
  - 背景が明るい色であることを確認する
- ダークグレー (#4d4d4d, #6c757d)
- アクセシビリティに配慮した高コントラストな組み合わせ
- ほぼ白のバリエーション (#ffffff から #f0f2f3)
  - 背景が暗い色であることを確認する

### 避けるべき色

設計仕様またはユーザー要求で明示的に必要とされていない限り、次は避けてください。

- 鮮やかな紫やマゼンタ
- 鮮やかなピンクやネオンカラー
- 彩度の高い暖色
- コントラスト比が低い色 (WCAG アクセシビリティ基準を満たさない)

### 控えめに使う色

**暖色** (赤、オレンジ、黄):

- 重大なアラート、警告、エラーメッセージに限定する
- 緊急性や重要性を伝える場合にのみ使う
- 大きな領域ではなく、小さなアクセント部分にとどめる
- 暖色を使う前に、アイコンや太字などの代替手段を検討する

## グラデーション

プロフェッショナルな見た目を保つため、グラデーションは控えめな色変化で適用してください。

### ベストプラクティス

- 色差は最小限にする (例: #E6F2FF から #F5F7FA)
- 同じ色系統の中でグラデーションを使う
- 1 つのグラデーションに暖色と寒色を混在させない
- 背景では radial より linear gradient を優先する

### 適切な用途

- 背景コンテナーとセクション
- ボタンの hover 状態やインタラクティブ要素
- ドロップシャドウや奥行き表現
- ヘッダーとナビゲーションバー
- カードコンポーネントとパネル
