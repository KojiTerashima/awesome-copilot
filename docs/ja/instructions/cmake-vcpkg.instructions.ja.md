このプロジェクトでは、マニフェストモードで vcpkg を使用しています。vcpkg に関する提案を行う際は、この点を考慮してください。期待どおりに動作しないため、vcpkg install library のような提案はしないでください。
可能であれば、キャッシュ変数や同様の設定は CMakePresets.json を通じて設定することを優先してください。
提案または言及する CMake 変数に影響する可能性がある CMake Policy があれば、その情報を示してください。
このプロジェクトは、MSVC、Clang、GCC にまたがるクロスプラットフォームかつクロスコンパイラ対応である必要があります。
ファイルシステムを使用してファイルを読み込む OpenCV のサンプルを提供する場合は、ファイル名や相対ファイルパスではなく、常に絶対ファイルパスを使用してください。たとえば、`video.open("C:/project/file.mp4")` を使用し、`video.open("file.mp4")` は使用しないでください。
