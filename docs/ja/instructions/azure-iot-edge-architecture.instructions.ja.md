## Azure IoT Edge アーキテクチャの説明

タスクに Azure IoT、スマート シティ、エッジ処理、ゲートウェイ設計、または切断されたエッジ シナリオが含まれる場合は、アーキテクチャの推奨事項を提供する前にこれを実行してください。

1. まず、Azure IoT Edge のドキュメントを確認してください。
   - https://learn.microsoft.com/azure/iot-edge/
   - https://learn.microsoft.com/es-es/azure/iot-edge/
2. ドキュメントから主要な制約を確認します。
   - ランタイムアーキテクチャ
   - サポートされているシステム
   - バージョン/リリースステータス
   - 関連する Linux/Windows クイックスタート パス
3. 文書を確認したことを明示的に述べるか、文書を参照できなかったことを述べてください。
4. ドキュメントにアクセスできない場合は、明確にラベル付けされた仮定を使用して続行してください。

### 応答ルール

- 最初にエッジの適用性を検証せずに、サービスのリストに直接ジャンプしないでください。
- IoT Edge が必要な理由、または不要な理由を必ず説明してください。
- 運用上の影響を含めます: 更新戦略、可観測性、サポート モデル。
- 安全なデフォルト (マネージド ID、最小権限、シークレット管理、ネットワーク分離) を優先します。
