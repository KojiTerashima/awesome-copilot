# PCF コミュニティ リソース

Power Apps Component Framework には、リソース、ツール、知識を作成して共有する活発なコミュニティがあります。このガイドでは、主要なコミュニティ リソースへのリンクを紹介します。

## PCF Gallery

**[PCF Gallery](https://pcf.gallery)**

PCF Gallery は、PCF component を見つけ、共有し、学ぶための中心的なハブです。

**ここで見つかるもの:**
- コミュニティ作成の component
- component のデモとスクリーンショット
- source code へのリンク
- インストール手順
- component の評価とレビュー
- 検索およびフィルター機能

**使い方:**
- category ごとに component を閲覧する
- 特定の機能を検索する
- project 用に component をダウンロードする
- 自分の component を投稿してコミュニティと共有する
- 実運用の component 実装から学ぶ

## コミュニティ ツール

### XrmToolBox 向け PCF Builder

**できること:**
- PCF component の作成を簡素化する
- visual manifest editor を提供する
- boilerplate code を生成する
- component テストを効率化する

**主な機能:**
- visual manifest designer
- property 構成 UI
- resource 管理
- すばやい component scaffold
- XrmToolBox ecosystem との統合

**向いている用途:**
- 素早い prototype 作成
- PCF 構造の学習
- component の迅速なセットアップ
- manifest の検証

### VS Code 向け PCF Builder

**できること:**
- PCF 開発を Visual Studio Code に統合する
- IntelliSense と code completion を提供する
- editor を離れずに workflow を簡素化する

**主な機能:**
- VS Code extension
- command palette 統合
- manifest schema 検証
- よくある pattern 用の code snippet
- 統合 terminal command

**向いている用途:**
- VS Code を好む開発者
- 効率化された workflow
- モダンな開発体験
- 組み込みのデバッグ支援

## コミュニティのベスト プラクティス

1. **自分の成果を共有する**: component と知識をコミュニティへ還元する
2. **フィードバックを提供する**: 問題を報告し、改善案を提案する
3. **十分に文書化する**: component には明確なドキュメントを含める
4. **十分にテストする**: 共有前に、component が各 platform で動くことを確認する
5. **標準に従う**: 確立された pattern と命名規則を使う
6. **役に立つ存在である**: 質問に答え、他の開発者を助ける

## PCF Gallery への貢献

component を PCF Gallery に追加するには、次の手順を行います。

1. 十分に文書化された component を作成する
2. 対象 platform 全体でテストする
3. スクリーンショットと demo を準備する
4. pcf.gallery に提出する
5. source code link (GitHub 推奨) を含める
6. 明確なインストール手順を提供する
