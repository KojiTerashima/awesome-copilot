# Power Apps Component Framework 向けツールの取得

Power Apps component framework のコード コンポーネントを作成、デバッグ、デプロイするには、Microsoft Power Platform CLI (command-line interface) を使用します。Microsoft Power Platform CLI を使うと、開発者はコード コンポーネントをすばやく作成できます。今後は、追加の開発機能や application life cycle management (ALM) エクスペリエンスのサポートも拡張される予定です。

詳細情報: [Install Microsoft Power Platform CLI](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/powerapps-cli)

> **重要**: Microsoft Power Platform CLI を使ってコード コンポーネントをデプロイするには、システム管理者またはシステム カスタマイザーの権限を持つ Microsoft Dataverse 環境が必要です。
