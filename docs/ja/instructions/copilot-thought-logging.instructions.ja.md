# コパイロットのプロセス追跡手順

**絶対的な必須ルール:**
- 手順のガイドライン全体を理解するには、手順を実行する前にこれらの手順をすべて確認する必要があります。
- これらの指示は、逸脱することなく指定どおりに正確に従う必要があります。
- 明示的に必要な場合を除き、処理中または説明中にステータスの更新を繰り返し続けないでください。これは問題があり、Copilot セッションコンテキストが溢れてしまいます。
- フェーズアナウンスなし (出力に「# Phase X」ヘッダーなし)
- フェーズは、一度に 1 つずつ、指定された正確な順序で実行する必要があります。
- 1 つの応答でフェーズを組み合わせることはありません
- フェーズのスキップなし
- 冗長な説明や解説はありません
- フェーズ命令で指定された正確なテキストのみを出力します

# フェーズ 1: 初期化

- ワークスペースのルートにファイル `\Copilot-Processing.md` を作成します
- `\Copilot-Processing.md` にユーザーリクエストの詳細を入力します
- 完了するまでアナウンスなしで黙々と作業します。
- このフェーズが完了したら、<フェーズ 1> が完了し、繰り返す必要がないことを心に留めておいてください。

# フェーズ 2: 計画

- アクションプランを `\Copilot-Processing.md` ファイルに生成します。
- ファイル `\Copilot-Processing.md` 内の todo/complete ステータスで各アクションプラン アイテムを追跡するために使用する、詳細で粒度の高いタスク固有のアクションアイテムを生成します。
- これには以下を含める必要があります。
  - フェーズとしてのアクションプラン内の各アクションアイテムの特定のタスク。
  - 何をする必要があるのか​​を明確に説明する
  - 各タスクの依存関係または前提条件
  - タスクが一度に 1 つずつ実行できるほど細分化されていることを確認する
- 完了するまでアナウンスなしで黙々と作業します。
- このフェーズが完了したら、<フェーズ 2> が完了し、繰り返す必要がないことを心に留めておいてください。

# フェーズ 3: 実行

- アクションプランのアクションアイテムを論理的なグループ/フェーズで実行します。
- 完了するまでアナウンスなしで黙々と作業します。
- ファイル `\Copilot-Processing.md` を更新し、アクションアイテムに追跡完了のマークを付けます。
- フェーズが完了したら、`\Copilot-Processing.md` からの特定のフェーズが完了し、繰り返す必要がないことを心に留めておいてください。
- すべてのアクションアイテムが完了するまでこのパターンを繰り返します

# フェーズ 4: まとめ

- `\Copilot-Processing.md` に概要を追加
- 完了するまでアナウンスなしで黙々と作業します。
- すべてのアクションが完了した場合にのみ実行します
- ユーザーに「最終概要を `\Copilot-Processing.md` に追加しました。」と通知します。
- 概要を確認してプロセスの完了を確認し、完了したらファイルを削除してリポジトリに追加されないようにするようユーザーに通知します。

**施行規則:**
- 応答には「# Phase X」ヘッダーを決して書き込まないでください
- 明示的に要求されない限り、出力内で「フェーズ」という単語を決して繰り返さないでください。
- 指定された正確なテキストを超える説明は決して提供しないでください
- 1 つの応答に複数のフェーズを決して組み合わせないでください。
- ユーザーの入力なしに現在のフェーズを超えて続行しないでください
- 冗長になっていると感じたら、停止して必要な出力のみを提供してください
- フェーズをスキップしそうになった場合は、停止して正しいフェーズに戻ります
- フェーズを組み合わせていることに気づいた場合は、停止して現在のフェーズのみを実行してください
