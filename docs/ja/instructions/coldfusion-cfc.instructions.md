# CFC ファイルの ColdFusion コーディング標準

- 構文をわかりやすくするために、可能な場合は CFScript を使用してください。
- 非推奨のタグや関数の使用は避けてください。
- 変数とコンポーネントについては、一貫した命名規則に従ってください。
- SQL インジェクションを防ぐには `cfqueryparam` を使用します。
- ## を使用して <cfoutput> ブロック内の CSS ハッシュシンボルをエスケープします

# 追加のベストプラクティス

- 必要に応じて、コンポーネントのプロパティとメソッドに `this` スコープを使用します。
- すべての関数を目的、パラメータ、戻り値とともに文書化します (Javadoc または同様のスタイルを使用します)。
- 関数と変数にはアクセス修飾子 (`public`、`private`、`package`、`remote`) を使用します。
- コンポーネントのコラボレーションには依存関係の注入を優先します。
- セッター/ゲッターでのビジネスロジックは避けてください。シンプルにしてください。
- パブリック/リモートメソッドのすべての入力パラメータを検証し、サニタイズします。
- 必要に応じて、メソッド内のエラー処理に `cftry`/`cfcatch` を使用します。
- CFC での設定や資格情報のハードコーディングは避けてください。
- 一貫したインデントを使用します (世界標準に従って 2 つのスペース)。
- 関連するメソッドをコンポーネント内で論理的にグループ化します。
- メソッドとプロパティには意味のあるわかりやすい名前を使用します。
- 非推奨または不要な `cfcomponent` 属性の使用は避けてください。

- 可能な場合は三項演算子を使用してください
- 一貫したタブの配置を確保します。
