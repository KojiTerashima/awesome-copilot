# シェルスクリプトガイドライン

bash、sh、zsh などのシェル向けに、クリーンで安全かつ保守しやすいシェルスクリプトを書くための指示です。

## 一般原則

- クリーンでシンプル、かつ簡潔なコードを生成する
- スクリプトが読みやすく理解しやすいことを保証する
- スクリプトの動作理解に役立つ箇所にはコメントを追加する
- 実行状況を伝える `echo` 出力は簡潔でわかりやすくする
- 不要な `echo` 出力や過剰なログ出力は避ける
- 利用可能な場合は静的解析に `shellcheck` を使う
- 明示がない限り、スクリプトは本番システムではなく自動化やテスト向けであると想定する
- 安全な展開を優先する: 変数参照は二重引用符で囲む (`"$var"`)、明確さのために `${var}` を使い、`eval` は避ける
- 移植性要件が許す場合は最新の Bash 機能 (`[[ ]]`、`local`、配列) を使い、必要な場合にのみ POSIX 構文へフォールバックする
- 構造化データの解析には、その場しのぎの文字列処理ではなく信頼できるパーサーを選ぶ

## エラーハンドリングと安全性

- `set -euo pipefail` を常に有効化し、エラー時に即時失敗し、未設定変数を検出し、パイプライン失敗を表面化させる
- 実行前に必須パラメーターをすべて検証する
- 文脈がわかる明確なエラーメッセージを出す
- スクリプト終了時に `trap` を使って一時リソースをクリーンアップしたり、予期しない終了を処理したりする
- 不変値は `readonly` (または `declare -r`) で宣言して、誤った再代入を防ぐ
- 一時ファイルや一時ディレクトリの作成には `mktemp` を使い、クリーンアップハンドラーで確実に削除する

## スクリプト構造

- 特に指定がなければ、先頭は明確な shebang `#!/bin/bash` で始める
- スクリプトの目的を説明するヘッダーコメントを含める
- すべての変数のデフォルト値を先頭で定義する
- 再利用可能なコードブロックには関数を使う
- 類似するコードブロックを繰り返す代わりに再利用可能な関数を作る
- メインの実行フローはクリーンで読みやすく保つ

## JSON と YAML の取り扱い

- その場しのぎの `grep`、`awk`、シェル文字列分割ではなく、専用パーサー (`jq` は JSON、`yq` は YAML、または `yq` で JSON 変換した上で `jq`) を優先する
- `jq` や `yq` が使えない、または適切でない場合は、その環境で使える次善の信頼できるパーサーを選び、安全な使い方を明示する
- 必須フィールドの存在を検証し、不足や不正なデータパスを明示的に処理する (`jq` の終了ステータス確認や `// empty` の使用など)
- シェル展開を防ぐため `jq`/`yq` フィルターは引用符で囲み、単純な文字列が必要な場合は `--raw-output` を優先する
- パーサーエラーは致命的なものとして扱う: `set -euo pipefail` と組み合わせるか、結果を使う前にコマンド成功を確認する
- スクリプト冒頭でパーサー依存関係を記載し、`jq`/`yq` (または代替ツール) が必要なのに未インストールなら、役立つメッセージとともに即時失敗させる

```bash
#!/bin/bash

# ============================================================================
# スクリプトの説明をここに記載
# ============================================================================

set -euo pipefail

cleanup() {
    # 必要に応じて一時リソースを削除するか、その他の後始末を行う
    if [[ -n "${TEMP_DIR:-}" && -d "$TEMP_DIR" ]]; then
        rm -rf "$TEMP_DIR"
    fi
}

trap cleanup EXIT

# デフォルト値
RESOURCE_GROUP=""
REQUIRED_PARAM=""
OPTIONAL_PARAM="default-value"
readonly SCRIPT_NAME="$(basename "$0")"

TEMP_DIR=""

# 関数
usage() {
    echo "使用方法: $SCRIPT_NAME [OPTIONS]"
    echo "オプション:"
    echo "  -g, --resource-group   リソースグループ (必須)"
    echo "  -h, --help            このヘルプを表示"
    exit 0
}

validate_requirements() {
    if [[ -z "$RESOURCE_GROUP" ]]; then
        echo "エラー: リソースグループは必須です"
        exit 1
    fi
}

main() {
    validate_requirements

    TEMP_DIR="$(mktemp -d)"
    if [[ ! -d "$TEMP_DIR" ]]; then
        echo "エラー: 一時ディレクトリの作成に失敗しました" >&2
        exit 1
    fi

    echo "============================================================================"
    echo "スクリプト実行開始"
    echo "============================================================================"

    # メインロジックをここに記載

    echo "============================================================================"
    echo "スクリプト実行完了"
    echo "============================================================================"
}

# 引数を解析
while [[ $# -gt 0 ]]; do
    case $1 in
        -g|--resource-group)
            RESOURCE_GROUP="$2"
            shift 2
            ;;
        -h|--help)
            usage
            ;;
        *)
            echo "不明なオプション: $1"
            exit 1
            ;;
    esac
done

# メイン関数を実行
main "$@"

```
