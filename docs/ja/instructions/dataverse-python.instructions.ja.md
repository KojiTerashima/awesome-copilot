# Dataverse SDK for Python — はじめに

- Dataverse Python SDK と前提パッケージをインストールします。
- Dataverse テナント、クライアント ID、シークレット、リソース URL 用の環境変数を設定します。
- SDK を使用して OAuth 認証を行い、CRUD 操作を実行します。

## セットアップ
- Python 3.10+
- 推奨: 仮想環境

## インストール
```bash
pip install dataverse-sdk
```

## 認証の基本
- Azure AD アプリ登録を使った OAuth を使用します。
- シークレットは `.env` に保存し、`python-dotenv` で読み込みます。

## よくあるタスク
- テーブルをクエリする
- 行を作成/更新する
- バッチ操作を行う
- ページングとスロットリングを処理する

## ヒント
- クライアントは再利用し、頻繁な再認証は避けます。
- 一時的な失敗に備えてリトライを追加します。
- トラブルシューティングのためにリクエストをログに残します。
