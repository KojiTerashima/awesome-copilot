### データ ファクトリの統合

Microsoft Fabric には、ETL/ELT オーケストレーション用の Data Factory が含まれています。

- **データ ソース用の 180 以上のコネクタ**
- データ移動のための **コピー アクティビティ**
- **Dataflow Gen2** による変換
- Spark 処理の **ノートブック アクティビティ**
- **スケジュール** とトリガー

### パイプライン活動

|アクティビティ |説明 |
|----------|-------------|
|データのコピー |ソースと Lakehouse の間でデータを移動する |
|ノート | Spark ノートブックを実行する |
|データフロー | Dataflow Gen2 変換を実行する |
|ストアド プロシージャ | SQL プロシージャを実行する |
|それぞれについて |アイテムをループする |
|条件 |条件分岐 |
|メタデータの取得 |ファイル/フォルダーのメタデータを取得する |
|レイクハウスのメンテナンス |デルタ テーブルの最適化とバキューム |

### オーケストレーション パターン

```
パイプライン: Daily_ETL_Pipeline
§── メタデータの取得（新しいファイルのチェック）
§── ForEach (ファイルごとに処理)
│ §── データコピー（ブロンズ層）
│ └── 手帳（シルバー変身）
§── ノート（金集合）
└── レイクハウスのメンテナンス（テーブルの最適化）
```
