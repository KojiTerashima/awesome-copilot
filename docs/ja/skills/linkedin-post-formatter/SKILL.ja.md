# LinkedIn投稿フォーマッター

生のコンテンツ、アイデア、技術的資料をUnicodeタイポグラフィと実績ある構造パターンを用いて、洗練されエンゲージメント最適化されたLinkedIn投稿に変換します。

## 概要

LinkedInはプレーンテキストのみ対応で、Markdownレンダリングやリッチフォーマットはサポートしていません。このスキルはUnicode数学的英数字記号を使い、外部ツールなしでLinkedInエディター上でネイティブに表示される太字・斜体・太字斜体テキストをシミュレートします。

## Unicodeタイポグラフィ参照

プレーンテキストをUnicodeスタイルのLinkedInテキストに変換する際は、まず `references/unicode-charmap.md` を権威ある文字マッピング参照として読み込み使用してください。

以下の文字マッピングを適用してプレーンテキストに視覚的強調を加えます：

### 太字（数学的サンセリフ太字）

重要なフレーズ、セクションヘッダー、強調したい単語に太字を使います。

| プレーン | Unicode太字 |
|----------|-------------|
| A-Z      | 𝗔-𝗭         |
| a-z      | 𝗮-𝘇         |
| 0-9      | 𝟬-𝟵         |

### 斜体（数学的サンセリフ斜体）

微妙な強調、技術用語、引用に斜体を使います。

| プレーン | Unicode斜体 |
|----------|-------------|
| A-Z      | 𝘈-𝘡         |
| a-z      | 𝘢-𝘻         |

### 太字斜体（数学的サンセリフ太字斜体）

最大限の強調に控えめに使用します。

| プレーン | Unicode太字斜体 |
|----------|-----------------|
| A-Z      | 𝘼-𝙕             |
| a-z      | 𝙖-𝙯             |

## 視覚的区切り線

視覚的構造を作るために以下の文字を使います：

- **セクション区切り**：`━━━━━━━━━━━━━━━━━━━━━━`（ボックス描画の太い横線）
- **箇条書き**：`◈`（点付きダイヤモンド）または `◎`（的）
- **矢印フロー**：縦方向は `↓`、横方向の継続は `→`
- **サブポイント**：インデントされた小項目に `↳`
- **番号付き項目**：太字Unicode数字 `𝟭. 𝟮. 𝟯.` などを使用

## フォーマットルール

1. **改行は重要**：LinkedInは複数の空行を折りたたみます。段落間は単一の空行を使いましょう。
2. **ファーストビューのフック**：最初の2〜3行で「もっと見る」をクリックさせる魅力を出す。価値を前倒しに。
3. **短い段落**：1〜3文以内。長文はエンゲージメントを下げます。
4. **太字は控えめに**：重要なフレーズや見出しに使い、段落全体は避ける。
5. **斜体はニュアンスに**：技術用語、内省、微妙な強調に使用。
6. **ハッシュタグは最後に**：5〜8個の関連ハッシュタグを最終行に。途中には入れない。
7. **本文に絵文字は原則禁止**：ユーザーが明示的に要求しない限り。例外はCTAの戦略的絵文字（♻️リポスト用）。
8. **文字数制限**：LinkedIn投稿は最大3000文字。最適なエンゲージメントは1500〜2500文字を目指す。
9. **本文にURL禁止**：リンク付き投稿はリーチが抑制される。リンクはコメント欄に。CTAで「コメント欄のリンク」や「下記から取得」などを案内。

## エンゲージメント最適化

- **効果的なオープニングフック**：質問、強い主張、「もしXなら…」、反対意見、驚きの統計。
- **効果的なクロージングCTA**：「♻️ 𝗥𝗲𝗽𝗼𝘀𝘁 なら…」「後で保存」「必要な人をタグ付け」「あなたの意見は？👇」
- **余白を活かす**：密集したテキストはスクロールされやすい。読みやすく空間を持たせる。
- **「もっと見る」フック**：LinkedInはデスクトップで約210文字で投稿を折りたたむ。最初の2行でクリックを誘う好奇心を作る。

## プロセス

1. ソースコンテンツ（テキスト、HTML、画像、アイデア）を分析。
2. 最適な投稿構造パターンを特定（フック→コンテンツ→CTA、リスティクル、ストーリー→レッスン、リソース共有）。
3. コアメッセージと3〜5の重要ポイントを抽出。
4. `references/unicode-charmap.md` を使い、ヘッダーや強調語にUnicode太字・斜体フォーマットを適用。
5. セクション間に視覚的区切り線を挿入。
6. 魅力的なフックを作成。
7. 最後にCTAとハッシュタグを追加。
8. LinkedInにコピペ可能な状態か検証。
