---

## ラウンドアップの使用方法

Copilot CLI に次のように指示することで、いつでもブリーフィングを生成できます。

- `use roundup` -- 過去 1 週間をカバーするブリーフィングを生成します。オーディエンスが 1 人の場合はそれを使用し、複数のオーディエンスがいる場合は Roundup がどのオーディエンスかを尋ねます。
- `use roundup -- leadership briefing for this week` -- 対象者と時間範囲を指定します
- `use roundup -- team update since Monday` -- 自然な表現であれば問題ありません
- `use roundup-setup` -- セットアップを再実行して対象読者、ソース、またはスタイルを変更します。
