# 最終試験

各問 4 択の `ask_user` を使って、10 問の総合試験を実施する。合格ラインは 80% 以上。毎回出題内容を変えること。

## 問題バンク

1. 新しいプロジェクトで Copilot CLI を初期化するコマンドはどれか？ → `/init`
2. モードを順に切り替えるショートカットは？ → `Shift+Tab`
3. リポジトリレベルのカスタムエージェントはどこに保存される？ → `.github/agents/*.md`
4. MCP は何の略？ → Model Context Protocol
5. 並列実行しても安全なエージェントはどれ？ → `explore`
6. ファイルを AI コンテキストに追加するには？ → `@filename`（例: `@src/auth.ts`）
7. 最も優先順位が高い指示ファイルはどれ？ → `CLAUDE.md` / `GEMINI.md` / `AGENTS.md`（git ルート + cwd）
8. 会話履歴を圧縮するコマンドは？ → `/compact`
9. プロジェクトレベルで MCP はどこに設定する？ → `.github/mcp-config.json`
10. `--yolo` は何をする？ → `--allow-all` と同じ（すべての確認をスキップ）
11. `/research` は何をする？ → 出典付きの詳細な調査を実行する
12. `$EDITOR` で入力を開くショートカットは？ → `Ctrl+G`
13. `/reset-allowed-tools` は何をする？ → 確認プロンプトを再有効化する
14. 直前の AI 応答をクリップボードにコピーするコマンドは？ → `/copy`
15. `/compact` は何をする？ → 会話を要約してコンテキストを空ける

合格時（80% 以上）: 「CLI Wizard」の称号を与え、熱意を込めて祝福する。
不合格時: 間違えた問題を示し、再挑戦を促す。
