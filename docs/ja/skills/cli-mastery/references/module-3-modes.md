# モジュール 3: 対話モード

## Interactive Mode（デフォルト）

- AI がプロンプトに対してすぐ行動する
- リスクのある操作では許可を求める
- 最適な用途: ちょっとした作業、デバッグ、コード探索
- 作業時間の 80% はここになる

## Plan Mode（`Shift+Tab` または `/plan`）

- AI がまず段階的な計画を作る
- 実行前にあなたがレビューして承認する
- 最適な用途: 複雑なリファクタリング、設計変更、危険な操作
- 重要な洞察: ミスのコストが高いときに使う

## Autopilot Mode（実験的、`/experimental`）

- AI が確認なしで行動する
- 最適な用途: 信頼できる環境、長時間かかる作業
- 注意して使うこと。`/allow-all` や `--yolo` と組み合わせる

## モード比較

| Feature | Interactive | Plan | Autopilot |
|---------|------------|------|-----------|
| 速度 | 速い | やや遅い | 最速 |
| 安全性 | 中 | 最高 | 最低 |
| 制御 | 各操作をあなたが承認 | 計画をあなたが承認 | AI に完全委任 |
| 最適な用途 | 日常タスク | 複雑な変更 | 反復的で信頼できる作業 |
| 切り替え | デフォルト | Shift+Tab または /plan | /experimental で有効化後、Shift+Tab |

教えるポイント: 適切なタイミングで適切なモードを使えば、生産性は 10 倍になる。
