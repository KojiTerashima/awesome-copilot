# モジュール 2: キーボードショートカット

## ナビゲーションと編集

| Shortcut | アクション |
|----------|--------|
| `@` | ファイルをメンションし、その内容をコンテキストとして含める |
| `Ctrl+S` | 入力テキストを保持したままプロンプトを送信する |
| `Shift+Tab` | モードを順に切り替える: Interactive → Plan |
| `Ctrl+T` | モデルの推論表示を切り替える |
| `Ctrl+O` | 最近のタイムラインを展開する（未入力時） |
| `Ctrl+E` | タイムライン全体を展開する（未入力時）/ 行末へ移動する（入力中） |
| `↑` `↓` | コマンド履歴を移動する |
| `!` | シェルコマンドを直接実行する（AI を経由しない） |
| `Esc` | 現在の操作をキャンセルする |
| `Ctrl+C` | 操作をキャンセル / 入力をクリア / 終了 |
| `Ctrl+D` | セッションを終了する |
| `Ctrl+L` | 画面をクリアする |
| `Ctrl+G` | 外部エディター（$EDITOR）でプロンプトを編集する |

## 行編集

| Shortcut | アクション |
|----------|--------|
| `Ctrl+A` | 行頭へ移動する |
| `Ctrl+H` | 直前の文字を削除する |
| `Ctrl+W` | 直前の単語を削除する |
| `Ctrl+U` | カーソル位置から行頭まで削除する |
| `Ctrl+K` | カーソル位置から行末まで削除する |
| `Meta+←` `Meta+→` | 単語単位でカーソルを移動する |

## 教えるべきプロのコツ

- `@` は最重要ショートカット。正確なコンテキストを渡す方法そのもの
- `!git status` は AI 処理を挟まずに git を直接実行する
- 複雑なタスクの前に `Shift+Tab` で Plan モードへ入る
- `Ctrl+G` は長いプロンプトを $EDITOR で開く。かなり強力
- `Ctrl+S` を使うと、再入力せずにプロンプトを反復改善できる
