# モジュール 1: スラッシュコマンド

これらのカテゴリを、例と「いつ使うか」のガイダンス付きで、一度に 1 つずつ教えること。

## はじめに

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/login` | GitHub で認証する | 初回起動時またはセッション期限切れ時 |
| `/logout` | サインアウトする | アカウントを切り替えるとき |
| `/help` | すべてのコマンドを表示する | 何をすればよいかわからないとき |
| `/exit` `/quit` | CLI を終了する | 作業を終えたとき |
| `/init` | copilot-instructions.md をひな形生成する | 新しいリポジトリのセットアップ |
| `/terminal-setup` | 複数行入力を設定する | 初回セットアップ |

## モデルとエージェント

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/model` | AI モデルを切り替える | 別の能力や速度が必要なとき |
| `/agent` | エージェントを閲覧・選択する | 専門家に委譲したいとき |
| `/fleet` | 並列サブエージェントを有効化する | 複雑で複数パートのタスク |
| `/tasks` | バックグラウンドタスクを表示する | 実行中のサブエージェントを確認するとき |

## コードとレビュー

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/diff` | 現在のディレクトリの変更を確認する | コミット前 |
| `/review` | コードレビューエージェントを実行する | 変更へのフィードバックが欲しいとき |
| `/lsp` | 言語サーバーを管理する | 定義ジャンプや診断が必要なとき |
| `/ide` | IDE ワークスペースに接続する | IDE 連携を使いたいとき |

## セッションとコンテキスト

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/context` | トークン使用量の可視化を表示する | コンテキストが大きくなってきたとき |
| `/usage` | セッションのメトリクスを表示する | プレミアムリクエスト数を確認したいとき |
| `/compact` | 会話履歴を圧縮する | コンテキスト上限に近いとき |
| `/session` | セッション情報を表示する | セッション詳細が必要なとき |
| `/resume` | 別のセッションに切り替える | 以前の作業を続けたいとき |
| `/rename` | 現在のセッション名を変更する | 整理しやすくしたいとき |
| `/share` | セッションを markdown/gist に出力する | チームと共有したいとき |
| `/copy` | 直前の応答をクリップボードにコピーする | AI の出力をすぐ取得したいとき |
| `/clear` | 会話履歴を消去する | まっさらな状態で始めたいとき |

## 権限とディレクトリ

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/allow-all` | すべての権限を有効にする | 信頼できる環境で素早く進めたいとき |
| `/add-dir` | 信頼済みディレクトリを追加する | 複数プロジェクトをまたいで作業するとき |
| `/list-dirs` | 許可済みディレクトリを表示する | アクセス範囲を確認したいとき |
| `/cwd` | 作業ディレクトリを変更する | プロジェクトの文脈を切り替えるとき |
| `/reset-allowed-tools` | ツール承認を取り消す | セキュリティを引き締めたいとき |

## 設定とカスタマイズ

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/instructions` | 有効な指示ファイルを表示する | カスタム挙動をデバッグするとき |
| `/experimental` | 実験的機能を切り替える | autopilot モードを試したいとき |
| `/theme` | ターミナルテーマを変更する | 見た目を自分好みにしたいとき |
| `/streamer-mode` | 機密情報を隠す | ライブ配信やデモ中 |
| `/changelog` | リリースノートを表示する | 更新後 |
| `/update` | CLI を更新する | 新しいバージョンがあるとき |
| `/feedback` | フィードバックを送信する | バグ報告や要望を出したいとき |

## 拡張性

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/skills` | スキルを管理する | 機能を閲覧・有効化したいとき |
| `/mcp` | MCP サーバーを管理する | 外部ツールを追加したいとき |
| `/plugin` | プラグインを管理する | 機能を拡張したいとき |

## ワークフローと調査

| Command | 何をするか | いつ使うか |
|---------|-------------|-------------|
| `/plan` | 実装計画を作成する | 複雑な変更の前 |
| `/research` | 詳細な調査を実行する | 出典付きで徹底分析したいとき |
| `/user` | GitHub ユーザー一覧を管理する | チーム文脈が必要なとき |

## クイズ（5 問以上、各問 4 択の `ask_user` を使う）

「どのコマンドを使って [scenario] を行う？」という形式の問題を出すこと。
