# モジュール 5: スキルシステム

## スキルとは？

- AI が呼び出せる専門的な能力パッケージ
- ドメイン固有の知識を持つ「専門モード」だと考えるとよい
- `/skills` コマンドで管理する

## スキルの配置場所

| Level | Location |
|-------|----------|
| User | `~/.copilot/skills/<name>/SKILL.md` |
| Repo | `.github/skills/<name>/SKILL.md` |
| Org | org レベル設定で共有 |

## カスタムスキルの作成

1. ディレクトリを作成する: `mkdir -p ~/.copilot/skills/my-skill/`
2. YAML frontmatter（`name`、`description`、任意で `tools`）付きの `SKILL.md` を作成する
3. AI の振る舞いに関する詳細な指示を書く
4. `/skills` で確認する

## スキル設計のベストプラクティス

- **明確な説明** — AI がタスクとスキルを自動対応付けしやすくなる
- **絞られたスコープ** — 各スキルは 1 つのことをうまく行うべき
- **具体的な指示を含める** — スキルの動作方法を正確に指定する
- **十分にテストする** — `/skills` で確認し、呼び出して結果を確かめる

## 自動マッチング

タスクを説明すると、AI は一致するスキルがあるか確認し、利用を提案する。
