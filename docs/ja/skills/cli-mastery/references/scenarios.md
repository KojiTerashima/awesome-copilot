# シナリオチャレンジ

これらを現実的な状況として提示する。各ステップでどのコマンドやショートカットを使うか、ユーザーに尋ねること。
各ステップには選択肢付きの `ask_user` を使う。

## シナリオ 1: プレッシャー下でのホットフィックスレビュー
> 本番バグ修正の準備ができている。差分を確認し、コードレビューを走らせ、さらにライブ配信中なので機密情報は隠しておきたい。

**Answer:** `/streamer-mode` → `/diff` → `/review @src/payment.ts`

## シナリオ 2: コンテキストウィンドウ救出
> セッションが巨大になり、モデル品質が落ちてきた。ノイズを減らしつつ継続性は維持したい。

**Answer:** `/context` → `/compact` → `/resume`（または `--continue` 付きで再起動）

## シナリオ 3: 自律リファクタースプリント
> 計画を確認して権限を設定した後、最小限のプロンプトでエージェントにリファクタリングを実行させたい。

**Answer:** `Shift+Tab`（Plan モード）→ 計画を検証 → `/allow-all` → Autopilot モードで実行

## シナリオ 4: エンタープライズ導入
> 新しいチーム用リポジトリにカスタムエージェント、リポジトリ指示、MCP 連携をセットアップする。

**Answer:** `.github/agents/` にエージェントプロファイルを追加し、`/instructions` を確認してから `/mcp add`

## シナリオ 5: パワー編集セッション
> 長いプロンプトを作っていて、文脈を失わずに素早く編集したい。

**Answer:** `Ctrl+G`（エディターで開く）、`Ctrl+A`（先頭へ移動）、`Ctrl+K`（後方を削る）

## シナリオ 6: エージェントオーケストレーション
> 複雑なプロジェクトを主導している。コードを理解し、テストを実行し、リファクタリングし、その後レビューしたい。

**Answer:** `explore` エージェント（理解）→ `task` エージェント（テスト）→ `general-purpose`（リファクタリング）→ `code-review`（検証）

## シナリオ 7: 新規プロジェクトセットアップ
> 新しいリポジトリをクローンし、最大限の生産性を得られるよう Copilot CLI をセットアップしたい。

**Answer:** `/init` → `/model` → `/mcp add`（必要なら）→ 最初のタスク前に `Shift+Tab` で Plan モードへ

## シナリオ 8: 本番安全性
> ひな形作業から本番デプロイスクリプト作業へ切り替える。

**Answer:** `/reset-allowed-tools` → Plan モード → 毎回コミット前に `/review`
