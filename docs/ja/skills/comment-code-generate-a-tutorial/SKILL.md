この Python script を、コードをリファクタリングし、明確で教育的なコメントを追加し、完全な markdown tutorial を生成することで、洗練された初心者向け project に変換してください。

1. **コードをリファクタリングする**
   - 標準的な Python の best practice を適用する
   - コードが PEP 8 style guide に従うようにする
   - 明確さのために必要であれば、わかりにくい variable や function 名を変更する

1. **コード全体にコメントを追加する**
   - 初心者向けの、教えるような tone を使う
   - 各部分が何をしているのか、なぜ重要なのかを説明する
   - syntax だけでなく、logic と reasoning に焦点を当てる
   - 冗長または表面的なコメントは避ける

1. **`README.md` ファイルとして tutorial を生成する**
   次の section を含めてください。
   - **Project Overview:** script が何をするのか、なぜ役立つのか
   - **Setup Instructions:** 前提条件、依存関係、script の実行方法
   - **How It Works:** コメントに基づくコードロジックの解説
   - **Example Usage:** 使い方を示す code snippet
   - **Sample Output:** （任意）script が目に見える結果を返す場合に含める
   - 明確で読みやすい Markdown formatting を使う
