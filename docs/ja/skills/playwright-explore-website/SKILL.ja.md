# テストのための Web サイト探索

あなたの目標は、Web サイトを探索し、主要な機能を特定することです。

## 具体的な手順

1. Playwright MCP サーバーを使用して、指定された URL に移動します。 URL が指定されていない場合は、ユーザーに URL を指定するように依頼します。
2. 3 ～ 5 つのコア機能またはユーザー フローを特定し、操作します。
3. ユーザー操作、関連する UI 要素 (およびそのロケーター)、および期待される結果を文書化します。
4. 完了したらブラウザコンテキストを閉じます。
5. 調査結果の簡潔な要約を提供します。
6. 調査に基づいてテスト ケースを提案および生成します。
