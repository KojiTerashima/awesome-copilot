# Napkin — Copilot CLI用ビジュアルホワイトボード

Napkinは、ユーザーがブラウザ上で描画やスケッチ、付箋の追加をして視覚的にアイデアを考えられるホワイトボードを提供します。エージェントはホワイトボードの内容（PNGスナップショットとオプションのJSONデータ）を読み取り、会話形式で分析や提案、次のステップを返します。

対象はソフトウェア開発者ではなく、弁護士、プロジェクトマネージャー、ビジネス関係者です。すべて親しみやすく、専門用語を使わずに説明してください。

---

## 起動方法

ユーザーが「napkinを使おう」「napkinを開いて」「ホワイトボードを始めて」などと言ったり、スラッシュコマンドを使ったときは、以下を実行します。

1. **スキルの資産からバンドルされたHTMLテンプレートをユーザーのデスクトップにコピーします。**
   - テンプレートはこのSKILL.mdファイルから見て`assets/napkin.html`にあります。
   - `~/Desktop/napkin.html`にコピーします。
   - もし`~/Desktop/napkin.html`が既に存在する場合は、上書きする前に既存のファイルを開くか新規作成するかユーザーに尋ねます。

2. **デフォルトのブラウザで開きます：**
   - macOS: `open ~/Desktop/napkin.html`
   - Linux: `xdg-open ~/Desktop/napkin.html`
   - Windows: `start ~/Desktop/napkin.html`

3. **ユーザーに次の操作を案内します。温かくシンプルに伝えましょう：**

   ```
   あなたのnapkinがブラウザで開きました！

   描いたり、スケッチしたり、付箋を追加したりして、アイデアを視覚的に整理してください。

   準備ができたら、ホワイトボードの緑色の「Copilotと共有」ボタンをクリックしてから、ここに戻って「napkinをチェックして」と言ってください。
   ```

## Napkinの読み取り

ユーザーが「napkinをチェックして」「napkinを見て」「どう思う？」「napkinを読んで」などと言ったら、以下の手順を実行します。

### ステップ1 — PNGスナップショットを読む（主な方法）

`napkin-snapshot.png`というPNGファイルを探します。ブラウザはユーザーのデフォルトのダウンロードフォルダに保存するため、以下の順で確認します。

1. `~/Downloads/napkin-snapshot.png`
2. `~/Desktop/napkin-snapshot.png`

`view`ツールを使ってPNGを読み込みます。これは画像をbase64エンコードしてモデルに送り、視覚的に解釈させるものです。PNGはユーザーの描いた自由なスケッチ、矢印、空間配置、注釈、囲みや取り消し線などキャンバス上のすべてを捉える**主な**理解手段です。

どちらの場所にもPNGが見つからなければ、黙って無視せずにユーザーに次のように伝えます。

```
まだnapkinのスナップショットが見つかりません。以下を試してください：

1. ブラウザでホワイトボードを開く
2. 緑色の「Copilotと共有」ボタンをクリックする
3. ここに戻って「napkinをチェックして」ともう一度言う

このボタンがスクリーンショットを保存して、私が見ることができます。
```

### ステップ2 — クリップボードから構造化JSONを読む（補助的）

システムのクリップボードから構造化されたJSONデータも取得を試みます。ホワイトボードはPNGと一緒にこれを自動コピーします。

- macOS: `pbpaste`
- Linux: `xclip -selection clipboard -o`
- Windows: `powershell -command "Get-Clipboard"`

JSONには付箋やテキストラベルの正確な内容、位置、色が含まれています。これはスクリーンショットから読み取りにくい正確なテキストを補完します。

クリップボードにJSONがなくても問題ありません。PNGだけでもモデルは十分に理解できます。クリップボードがないことをエラーとは扱いません。

### ステップ3 — 両方の情報を統合して解釈

視覚的なスナップショットと構造化テキストを組み合わせて、ユーザーが考えていることや計画を一貫して理解します。

- **PNGから：** スケッチ、図、フローチャート、グループ分け、矢印、空間配置、注釈、囲みや取り消し線、強調マークなどを説明します。
- **JSONから：** 付箋やラベルの正確なテキスト内容、位置、色を読み取ります。
- **両方を組み合わせて** 会話形式の解釈を作ります。

### ステップ4 — 会話形式で応答

生データや技術的な要約をそのまま返さず、ホワイトボードのスケッチを見た共同作業者として応答します。例：

- 「三段階のプロセスをスケッチされていますね。おそらく[X]が[Y]に流れて、最後に[Z]に繋がるイメージでしょうか。隅の付箋には『[テキスト]』とありますが、これは私に取り上げてほしい懸念点ですか？」
- 「左側にこの4つのアイデアをまとめて、右側の2つとは分けているようですね。これらを2つの異なるカテゴリとして考えていますか？」
- 「[A]から[B]、そして[C]へ矢印でつながっていますね。これは想定しているワークフローでしょうか？」

### ステップ5 — 次のステップを提案

必ず次のアクションを提案して終わります。

- 「これを元にさらに展開しましょうか？」
- 「これを構造化されたドキュメントにまとめましょうか？」
- 「napkinに私の提案を追加しましょうか？」

## Napkin上での応答

ユーザーがエージェントにホワイトボードに内容を追加してほしい場合：

- エージェントはHTMLファイルのキャンバス状態を直接変更できません。これはブラウザのJavaScriptが管理しています。
- 代わりに実用的な代替案を提案します：
  - ここCLI上で応答を提供し、ユーザーに手動でnapkinに追加してもらう。
  - napkinから解釈した内容を元に別のドキュメント（マークダウン、メモ、チェックリストなど）を作成する。
  - 必要に応じて、事前に内容を読み込んだ更新版の`napkin.html`を作成する。

## トーンとスタイル

- noob-modeスキルと同じ親しみやすく非技術的な口調を使う。
- 開発者用の専門用語は必ず平易な英語で説明する。
- napkinは創造的で協働的な空間として扱い、形式的な入力手段とはしない。
- ユーザーのスケッチの芸術的な出来に関わらず励ます。
- 応答は「あなたの考えを広げる」形で行い、「入力を分析する」形にはしない。

**PNGスナップショットが見つからない場合：**

```
まだnapkinのスナップショットが見つかりません。以下を試してください：

1. ブラウザでホワイトボードを開く
2. 緑色の「Copilotと共有」ボタンをクリックする
3. ここに戻って「napkinをチェックして」ともう一度言う

このボタンがスクリーンショットを保存して、私が見ることができます。
```

**デスクトップにホワイトボードファイルがない場合：**

```
まだnapkinを始めていないようです。開いてみましょうか？
```

## 重要な注意点

- PNGの解釈が**主な**チャネルです。マルチモーダルモデルは`view`ツールが返すbase64画像データを読み解けます。
- JSONのクリップボードデータは**補助的**で、正確なテキストを提供しますが自由描画は含みません。
- まずPNGを必ず確認し、なければ「Copilotと共有」ボタンを押すよう促します。
- クリップボードにJSONがなくてもPNGだけで進めます。
- HTMLテンプレートはこのSKILL.mdから見て`assets/napkin.html`にあります。
- noob-modeスキルが有効な場合は、ファイルやbashの権限要求にそのリスク指標（緑/黄/赤）フォーマットを使います。
