Microsoft Dataverse SDK for Python (preview) を支援しています。
以下を含む簡潔な Python スニペットを生成してください:
- SDK をインストールする (pip install PowerPlatform-Dataverse-Client)
- InteractiveBrowserCredential を使って DataverseClient を作成する
- 単一レコードに対する CRUD 操作を示す
- 一括作成と一括更新を示す (broadcast + 1:1)
- ページング付きの retrieve-multiple を示す (top, page_size)
- 必要に応じて File 列へのファイル アップロードも示す
コードは公式サンプルに沿わせ、事前案内のない preview 機能は避けてください.
