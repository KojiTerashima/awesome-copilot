# Issueテンプレート

これらのテンプレートをコピーして、Issue本文用にカスタマイズしてください。

## バグ報告テンプレート

```markdown
## 説明
[バグの明確な説明]

## 再現手順
1. [最初の手順]
2. [2番目の手順]
3. [以下同様...]

## 期待される動作
[本来起こるべきこと]

## 実際の動作
[実際に起きていること]

## 環境
- Browser: [例: Chrome 120]
- OS: [例: macOS 14.0]
- Version: [例: v1.2.3]

## スクリーンショット/ログ
[必要に応じて]

## 追加情報
[その他の関連情報]
```

## 機能要望テンプレート

```markdown
## 概要
[機能の1行説明]

## 背景・目的
[なぜこの機能が必要ですか？どの問題を解決しますか？]

## 提案する解決策
[この機能はどのように動作すべきですか？]

## 受け入れ基準
- [ ] [基準 1]
- [ ] [基準 2]
- [ ] [基準 3]

## 検討した代替案
[検討した他のアプローチと、採用しなかった理由]

## 追加情報
[モックアップ、例、または関連Issue]
```

## タスクテンプレート

```markdown
## 目的
[達成すべきこと]

## 詳細
[作業内容の詳細説明]

## チェックリスト
- [ ] [サブタスク 1]
- [ ] [サブタスク 2]
- [ ] [サブタスク 3]

## 依存関係
[ブロッカーや関連作業]

## メモ
[追加の背景情報や考慮事項]
```

## 最小テンプレート

シンプルなIssue向け:

```markdown
## 説明
[何を、なぜ]

## タスク
- [ ] [タスク 1]
- [ ] [タスク 2]
```
