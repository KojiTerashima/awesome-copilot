---
name: my-pull-requests
description: '現在のリポジトリ内の自分のプルリクエストを一覧表示する'
---

現在のリポジトリ（#githubRepoでリポジトリ情報を取得）を検索し、自分に割り当てられているプルリクエスト（#list_pull_requestsを使用）をすべて一覧表示してください。

各プルリクエストの目的と詳細を説明してください。

レビュー待ちのプルリクエストがあれば、そのことをレスポンスで強調してください。

プルリクエストにチェック失敗があった場合は、それらを説明し、考えられる修正案を提案してください。

Copilotによるレビューが行われていない場合は、#request_copilot_reviewを使ってレビューを依頼することを提案してください。
