# MCPベースエージェントの展開と管理

Microsoft 365の管理センターを使用して、組織配布と制御のためにMCPベースの宣言型エージェントを展開、管理、ガバナンスします。

## エージェントの種類

### 組織による公開
- 事前定義された指示とアクションで構築
- 予測可能なタスクのための構造化されたロジックに従う
- 管理者の承認と公開プロセスが必要
- コンプライアンスとガバナンス要件をサポート

### 作成者による共有
- Microsoft 365 Copilot StudioまたはAgent Builderで作成
- 特定のユーザーと直接共有
- 検索、アクション、コネクタ、APIによる機能強化
- 管理者がエージェントレジストリで確認可能

### Microsoftエージェント
- Microsoftによって開発および維持
- Microsoft 365サービスと統合
- 事前承認済みで即使用可能

### 外部パートナーエージェント
- 認証済みの外部開発者/ベンダーによって作成
- 管理者の承認と制御対象
- 利用可能性と権限の設定が可能

### フロンティアエージェント
- 実験的または高度な機能
- 限定的な展開や追加監視が必要な場合あり
- 例：
  - **App Builderエージェント**：M365 CopilotまたはPower Platform管理センターで管理
  - **Workflowsエージェント**：Power Platform管理センターで管理されるフロー自動化

## 管理者の役割と権限

### 必須ロール
- **AI管理者**：完全なエージェント管理権限
- **グローバルリーダー**：閲覧のみ（編集不可）

### ベストプラクティス
- 最小権限のロールを使用
- グローバル管理者は緊急時のみ限定使用
- 最小権限の原則を遵守

## Microsoft 365管理センターでのエージェント管理

### エージェント管理へのアクセス
1. [Microsoft 365管理センター](https://admin.microsoft.com/)にアクセス
2. **エージェント**ページに移動
3. 利用可能、展開済み、またはブロックされたエージェントを表示

### 利用可能な操作

**エージェントの表示**
- 利用状況（利用可能、展開済み、ブロック）でフィルター
- 特定のエージェントを検索
- エージェントの詳細（名前、作成者、日付、ホスト製品、状態）を表示

**エージェントの展開**
配布オプション：
1. **エージェントストア**：パートナーセンターに提出し検証および公開
2. **組織展開**：IT管理者が全員または選択した従業員に展開

**エージェントライフサイクルの管理**
- **公開**：組織で利用可能にする
- **展開**：特定のユーザーまたはグループに割り当て
- **ブロック**：エージェントの使用を禁止
- **削除**：組織からエージェントを削除

**アクセスの設定**
- 特定ユーザーグループの利用可能性を設定
- エージェントごとの権限を管理
- Copilotに表示されるエージェントを制御

## 展開ワークフロー

### 組織への公開

**エージェント開発者向け：**
1. Microsoft 365 Agents Toolkitでエージェントを構築
2. 開発環境で十分にテスト
3. 承認のためにエージェントを提出
4. 管理者のレビューを待つ

**管理者向け：**
1. 管理センターで提出されたエージェントをレビュー
2. コンプライアンスとセキュリティを検証
3. 組織利用の承認
4. 展開設定を構成
5. 選択ユーザーまたは組織全体に公開

### エージェントストア経由の展開

**開発者の手順：**
1. エージェントの開発とテストを完了
2. 提出用にパッケージ化
3. パートナーセンターに提出
4. 検証プロセスを待機
5. 承認通知を受領
6. Copilotストアにエージェントが表示される

**管理者の手順：**
1. Copilotストアでエージェントを発見
2. エージェントの詳細と権限を確認
3. 組織またはユーザーグループに割り当て
4. 利用状況とフィードバックを監視

### 組織エージェントの展開

**管理者の展開オプション：**
```
組織全体：
- Copilotライセンスを持つ全従業員
- Copilotで自動的に利用可能

グループベース：
- 特定の部門またはチーム
- セキュリティグループ割り当て
- 役割ベースアクセス制御
```

**設定手順：**
1. 管理センターのエージェントページに移動
2. 展開するエージェントを選択
3. 展開範囲を選択：
   - 全ユーザー
   - 特定のセキュリティグループ
   - 個別ユーザー
4. 利用可能状態を設定
5. 必要に応じて権限を構成
6. 展開して監視

## ユーザー体験

### エージェントの発見
ユーザーは以下でエージェントを見つける：
- Microsoft 365 Copilotハブ
- Copilotインターフェースのエージェントピッカー
- 組織のエージェントカタログ

### エージェントアクセス制御
ユーザーは：
- 対話中にエージェントのオン/オフを切り替え可能
- エージェントの追加/削除が可能
- エージェントを右クリックして設定を管理
- 管理者が許可したエージェントのみアクセス可能

### エージェントの利用
- エージェントはCopilotサイドバーに表示
- ユーザーはコンテキストに応じてエージェントを選択
- クエリは選択されたエージェント経由で処理
- 応答はエージェントの機能を活用

## ガバナンスとコンプライアンス

### セキュリティ考慮事項
- **データアクセス**：エージェントがアクセス可能なデータを確認
- **API権限**：必要なスコープを検証
- **認証**：安全なOAuthフローを確保
- **外部接続**：外部統合のリスクを評価

### コンプライアンス要件
- **データ所在**：データが境界内に留まることを確認
- **プライバシーポリシー**：エージェントのプライバシーステートメントを確認
- **利用規約**：許容される使用ポリシーを検証
- **監査ログ**：エージェントの利用と活動を監視

### 監視と報告
追跡項目：
- エージェントの採用率
- ユーザーフィードバックと満足度
- エラー率とパフォーマンス
- セキュリティインシデントや違反

## MCP固有の管理

### MCPエージェントの特徴
- Model Context Protocol経由で外部システムに接続
- MCPサーバーが公開するツールを使用
- OAuth 2.0またはSSO認証が必要
- REST APIエージェントと同様のガバナンスをサポート

### MCPエージェントの検証
確認事項：
- MCPサーバーURLがアクセス可能
- 認証設定が安全
- インポートされたツールが適切
- 応答データに機密情報が含まれない
- サーバーがセキュリティベストプラクティスに準拠

### MCPエージェントの展開
REST APIエージェントと同様のプロセス：
1. 管理センターでレビュー
2. MCPサーバーの準拠性を検証
3. 認証フローをテスト
4. ユーザー/グループに展開
5. パフォーマンスを監視

## エージェント設定と構成

### 組織設定
テナントレベルで構成：
- エージェント作成の有効/無効
- デフォルト権限の設定
- 承認ワークフローの構成
- コンプライアンスポリシーの定義

### エージェントごとの設定
個別エージェントに対して構成：
- 利用可能性（オン/オフ）
- ユーザー割り当て（全員/グループ/個人）
- 権限スコープ
- 利用制限またはクォータ

### 環境ルーティング
Power Platformベースのエージェント向け：
- デフォルト環境の構成
- Copilot Studio用の環境ルーティングを有効化
- Power Platform管理センターでフローを管理

## 共有エージェント管理

### 共有エージェントの表示
管理者は以下を確認可能：
- すべての共有エージェント一覧
- 作成者情報
- 作成日
- ホスト製品
- 利用可能状態

### 共有エージェントの管理
管理者の操作：
- 特定の共有エージェントを検索
- エージェントの機能を表示
- 安全でないまたは非準拠のエージェントをブロック
- エージェントのライフサイクルを監視

### ユーザーの共有エージェントアクセス
ユーザーは以下を通じてアクセス：
- Microsoft 365 Copilotの各種画面
- エージェント固有のタスクと支援
- 作成者定義の機能

## ベストプラクティス

### 展開前
- 小規模ユーザーグループで**パイロットテスト**
- 初期利用者から**フィードバック収集**
- **セキュリティとコンプライアンスの検証**
- エージェントの機能と制限を**文書化**
- ユーザーに対する**トレーニング**

### 展開中
- **段階的展開**で採用を管理
- **パフォーマンスとエラーを監視**
- 継続的に**フィードバック収集**
- 問題を迅速に**対応**
- ユーザーに対して**利用可能性を周知**

### 展開後
- **指標を追跡**：採用率、満足度、エラー
- フィードバックに基づき**改善**
- 新機能で**エージェントを更新**
- 使われなくなったエージェントは**廃止**
- 定期的に**セキュリティとコンプライアンス監査**

### コミュニケーション
- 新エージェントをユーザーに**告知**
- ドキュメントと例を提供
- ベストプラクティスとユースケースを共有
- 利点と機能を強調
- サポートチャネルを提供

## トラブルシューティング

### エージェントが表示されない
- 管理センターで展開状況を確認
- ユーザーが割り当てグループに含まれているか確認
- エージェントがブロックされていないか確認
- ユーザーがCopilotライセンスを持っているか確認
- Copilotインターフェースを更新

### 認証失敗
- OAuth資格情報が有効か確認
- ユーザーに必要な権限があるか確認
- MCPサーバーがアクセス可能か確認
- 認証フローを独立してテスト

### パフォーマンス問題
- MCPサーバーの応答時間を監視
- ネットワーク接続を確認
- 管理センターのエラーログを確認
- エージェントがレート制限されていないか検証

### コンプライアンス違反
- 危険な場合は即座にエージェントをブロック
- 監査ログで違反を確認
- データアクセスパターンを調査
- 再発防止のためポリシーを更新
