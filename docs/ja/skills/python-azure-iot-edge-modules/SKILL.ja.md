# Python Azure IoT エッジ モジュール

このスキルを使用して、テレメトリ処理、ローカル推論、プロトコル変換、エッジからクラウドへの統合のための Python ベースの IoT Edge モジュールを設計、実装、検証します。

## いつ使用するか

このスキルは次のようなリクエストに使用します。

- 「IoT Edge用のPythonモジュールを作成したい」
- 「マニフェストを使用してエッジ モジュールをデプロイするにはどうすればよいですか」
- 「テレメトリをアップロードする前にフィルタリング/追加する必要があります。」
- 「エッジでの切断と再試行をどのように処理すればよいですか」

## 必須の文書レビュー

実行時の動作や展開に関する決定を推奨する前に、以下を確認してください。

- https://learn.microsoft.com/azure/iot-edge/
- https://learn.microsoft.com/es-es/azure/iot-edge/

最小限のチェック:

- ランタイム アーキテクチャとモジュールのライフサイクル。
- サポートされているホスト OS とバージョン。
- 導入モデルと構成フロー。
- 現在のリリース/バージョンのガイダンス。

ドキュメントを取得できない場合は、明確な仮定を立てて続行し、それらに明確にフラグを立てます。

## Python 公式リファレンスとベスト プラクティス (必須)

Python 実装の詳細を提案する前に、公式の Python ソースを参照してください。

- https://www.python.org/
- https://docs.python.org/3/
- https://docs.python.org/3/reference/
- https://docs.python.org/3/library/
- 参考文献/python-official-best-practices.md

互換性に関する特別な理由がない限り、コミュニティ スニペットよりも公式ドキュメントを優先してください。

## 目標

- 実稼働を中心としたモジュール アーキテクチャと実装計画を提供します。
- ネットワークが変動しても信頼性の高いエッジ メッセージングを保証します。
- デプロイメント、可観測性、および検証のアーティファクトを提供します。

## モジュールの使用例

- プロトコル アダプター (シリアル/Modbus/OPC-UA から IoT メッセージ形式)。
- テレメトリの強化と正規化。
- ローカルな異常の検出または推論。
- コマンドオーケストレーションとローカルアクチュエーター制御。

## 納品ワークフロー

### 1) コントラクトとインターフェース

定義する：

- モジュールの入力と出力。
- メッセージ スキーマとバージョン管理ポリシー。
- 通常のテレメトリとクリティカルなテレメトリのルートと優先順位。
- 動的構成に使用される必要なプロパティ。

### 2) ランタイムとパッケージ化

特定：

- Python ランタイム バージョンのターゲット。
- コンテナー イメージ戦略 (基本イメージ、スリムなフットプリント、CVE 健全性)。
- リソース プロファイル (CPU/メモリ境界)。
- 起動とヘルスチェック。

### 3) 信頼性設計

実装して検証します。

- 指数バックオフとジッターを伴う再試行。
- アップストリーム障害時の正常な機能低下。
- 必要に応じてローカル キュー戦略。
- 再生されたメッセージの冪等処理。

### 4) セキュリティ管理

必要とする：

- コードまたはマニフェストに平文のシークレットはありません。
- 最小権限のモジュールの動作。
- 安全なトランスポートと信頼できる証明書チェーンの処理。
- コマンド処理と状態変化のトレーサビリティ。

### 5) 導入と運用

定義する：

- 環境固有の展開マニフェスト。
- ロールアウト戦略 (パイロット、段階的、広範囲)。
- ロールバック基準。
- SLO とアラート条件。
