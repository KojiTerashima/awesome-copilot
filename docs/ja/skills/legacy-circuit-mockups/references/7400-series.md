# 7400シリーズロジックIC仕様

## 1. 概要

**7400シリーズ**は、もともと**TTL（トランジスタ・トランジスタ・ロジック）**で実装され、その後**CMOS互換バリアント**も加えられた大規模な**デジタルロジック集積回路**のファミリーです。これらのデバイスは、ゲート、フリップフロップ、カウンター、マルチプレクサ、デコーダ、バストランシーバなどの基本的な構成要素を提供します。

7400シリーズICは、**レトロコンピューティング**、**6502/Z80システム**、**グルーロジック**、教育用設計で広く使用されています。

## 2. ロジックファミリー

| ファミリー | 技術                   | 備考                     |
| ---------- | ---------------------- | ------------------------ |
| 74xx       | TTL                    | オリジナルのバイポーラTTL |
| 74LSxx     | 低消費電力ショットキTTL | 高速、低消費電力          |
| 74HCTxx    | CMOS（TTLレベル入力）   | 混在システムに最適        |
| 74HCxx     | CMOS                   | 広い電圧範囲             |
| 74ACTxx    | 高度なCMOS TTLレベル    | 非常に高速               |

## 6. ピン番号の規則

* DIPパッケージは**反時計回りの番号付け**
* ピン1はノッチまたはドットで識別

```text
       ________
  1 °|       |° 14
  2 °|        |° 13
  3 °|        |° 12
  4 °|        |° 11
  5 °|        |° 10
  6 °|        |°  9
  7 °|________|°  8
```

## 8. タイミング特性（一般）

| パラメータ         | TTL       | CMOS       |
| ------------------ | --------- | ---------- |
| 伝搬遅延           | 5-15 ns   | 8-25 ns    |
| 最大周波数         | 約25 MHz  | 約50 MHz以上 |

---

## 9. インターフェースに関する注意

* TTL出力はTTL入力を確実に駆動
* CMOS入力はフロートさせてはいけない
* CMOSとTTL信号のインターフェースには**74HCT**を使用
* 各ICに0.1 µFのデカップリングコンデンサが必要
