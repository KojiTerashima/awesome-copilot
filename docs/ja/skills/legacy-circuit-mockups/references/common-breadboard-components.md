# 一般的なブレッドボード電子部品

**ブレッドボードベースの電子工作**に役立つ実用的なリファレンスで、一般的な部品、公式、表、ピン配置、学習参考資料を網羅。初心者から中級のハードウェア製作者に適しています。

---

## 1. 抵抗器

### 説明

抵抗器は電流を制限し、電圧を分割し、バイアスポイントを設定します。

### 一般的な種類

| 種類           | 備考        | 典型的な用途        |
| -------------- | ----------- | ------------------- |
| カーボンフィルム | 安価、±5%   | 汎用                |
| メタルフィルム   | 安定、±1%   | 精密回路            |
| ワイヤーワウンド | 高出力      | 電力消費            |
| ポテンショメータ | 調整可能    | ボリューム、調整    |

### 標準値（E12シリーズ）

`10, 12, 15, 18, 22, 27, 33, 39, 47, 56, 68, 82 x 10^n`

### カラーコード

| バンド | 意味          |
| ------ | ------------- |
| 1      | 第1数字       |
| 2      | 第2数字       |
| 3      | 乗数          |
| 4      | 許容誤差      |

### 定格電力

| 定格   | 典型的なサイズ      |
| ------ | ------------------- |
| 1/8 W  | 小型                |
| 1/4 W  | ブレッドボード標準  |
| 1/2 W  | 大型                |

### 公式

* **オームの法則:** `V = I x R`
* **電力:** `P = V × I = I² × R = V² / R`

### 参考

* [https://en.wikipedia.org/wiki/Resistor](https://en.wikipedia.org/wiki/Resistor)

## 2. コンデンサ

### 説明

コンデンサは電気エネルギーを蓄え、直流を遮断し交流を通します。

### 一般的な種類

| 種類         | 極性あり | 典型的な用途       |
| ------------ | -------- | ------------------ |
| セラミック   | なし     | デカップリング、バイパス |
| 電解         | あり     | 大容量フィルタリング |
| タンタル     | あり     | コンパクトフィルタリング |
| フィルム     | なし     | 信号結合           |

### 一般的な値

| 範囲 | 例               |
| ---- | ---------------- |
| pF   | 10pF、100pF      |
| nF   | 100nF（0.1µF）   |
| µF   | 1µF、10µF、100µF |

### 電圧定格のルール

> コンデンサの電圧定格 ≥ **回路電圧の2倍**

### 公式

* **容量性リアクタンス:** `Xc = 1 / (2πfC)`
* **蓄積エネルギー:** `E = ½ C V²`

### 参考

* [https://en.wikipedia.org/wiki/Capacitor](https://en.wikipedia.org/wiki/Capacitor)

---

## 3. インダクタ

### 説明

インダクタは磁場にエネルギーを蓄え、電流の変化に抵抗します。

### 一般的な種類

| 種類         | 用途               |
| ------------ | ------------------ |
| エアコア     | 高周波回路         |
| フェライトコア | 電源フィルタリング |
| チョーク     | ノイズ抑制          |

### 公式

* **誘導性リアクタンス:** `XL = 2πfL`

### 参考

* [https://en.wikipedia.org/wiki/Inductor](https://en.wikipedia.org/wiki/Inductor)

---

## 4. ダイオード

### 説明

ダイオードは一方向にのみ電流を流します。

### 一般的な種類

| 種類       | 代表部品   | 用途                   |
| ---------- | ---------- | ---------------------- |
| 整流       | 1N4007     | 電源                   |
| 信号       | 1N4148     | ロジック、高速スイッチング |
| ゼナ       | 1N4733A    | 電圧調整               |
| ショットキー | 1N5819     | 低降下電圧             |

### 主要パラメータ

| パラメータ       | 典型値                     |
| ---------------- | -------------------------- |
| 順方向電圧       | 0.7V（Si）、0.3V（ショットキー） |
| 逆方向電圧       | デバイス依存               |

### 参考

* [https://en.wikipedia.org/wiki/Diode](https://en.wikipedia.org/wiki/Diode)

## 5. LED（発光ダイオード）

### 説明

LEDは順方向バイアス時に光を発します。

### 典型的な順方向電圧

| 色     | Vf        |
| ------ | --------- |
| 赤     | 1.8-2.2V  |
| 緑     | 2.0-3.0V  |
| 青     | 3.0-3.3V  |

### 電流制限抵抗

`R = (V_supply - V_LED) / I_LED`

### 参考

* [https://en.wikipedia.org/wiki/Light-emitting_diode](https://en.wikipedia.org/wiki/Light-emitting_diode)

## 9. ブレッドボード

### 説明

はんだ付け不要の試作ボードで内部にバス接続があります。

### 内部配線

* 行：横方向に接続（5穴）
* レール：縦方向に接続（電源）

### 制限事項

* 高周波や大電流回路には不向き

### 参考

* [https://en.wikipedia.org/wiki/Breadboard](https://en.wikipedia.org/wiki/Breadboard)
