# AT28C256 EEPROMを用いた6502アセンブリ言語

シングルボードコンピュータ（SBC）やレトロシステムにおいて、**AT28C256（32KB）並列EEPROM**に格納し実行することを想定した**6502/65C02アセンブリ言語プログラム**の実用的仕様。

---

## 1. 範囲と前提条件

本書は以下を前提とする：

* **6502ファミリーCPU**（6502、65C02、または互換）
* プログラムコードは**AT28C256（32K×8）EEPROM**に格納
* メモリマップドI/O（例：6522 VIA）
* リセットおよび割り込みベクタはEEPROM内に配置
* 外部RAMは別のアドレス空間にマップ（例：62256 SRAM）

---

## 2. AT28C256 EEPROM概要

| パラメータ       | 値                   |
| ---------------- | -------------------- |
| 容量             | 32 KB（32768バイト） |
| アドレス線       | A0-A14               |
| データ線         | D0-D7                |
| アクセスタイム   | 約150 ns             |
| 電源電圧         | 5 V                  |
| パッケージ       | DIP-28 / PLCC        |

### 典型的なメモリマップ使用例

| アドレス範囲    | 用途                      |
| --------------- | ------------------------- |
| `$8000-$FFFF`   | EEPROM（コード＋ベクタ）  |
| `$FFFA-$FFFF`   | 割り込みベクタ            |

---

## 3. 6502メモリマップ例

```
$0000-$00FF  ゼロページ（RAM）
$0100-$01FF  スタック
$0200-$7FFF  RAM / I/O
$8000-$FFFF  AT28C256 EEPROM
```

---

## 4. リセットおよび割り込みベクタ

6502は**メモリの最上位**からベクタを読み込む：

| ベクタ   | アドレス       | 説明                   |
| -------- | -------------- | ---------------------- |
| NMI      | `$FFFA-$FFFB`  | ノンマスカブル割り込み |
| RESET    | `$FFFC-$FFFD`  | リセットエントリポイント |
| IRQ/BRK  | `$FFFE-$FFFF`  | マスク可能割り込み     |

### ベクタ定義例

```asm
        .org $FFFA
        .word nmi_handler
        .word reset
        .word irq_handler
```

---

## 5. アセンブリプログラム構造

### 典型的なレイアウト

```asm
        .org $8000

reset:
        sei             ; IRQを無効化
        cld             ; 10進モードクリア
        ldx #$FF
        txs             ; スタック初期化

main:
        jmp main
```

---

## 6. 基本的な6502命令

### レジスタ

| レジスタ | 用途             |
| -------- | ---------------- |
| A        | アキュムレータ   |
| X, Y     | インデックスレジスタ |
| SP       | スタックポインタ |
| PC       | プログラムカウンタ |
| P        | プロセッサステータス |

### よく使う命令

| 命令       | 機能                   |
| ---------- | ---------------------- |
| LDA/STA    | アキュムレータの読み書き |
| LDX/LDY    | インデックスレジスタの読み込み |
| JMP/JSR    | ジャンプ / サブルーチン呼び出し |
| RTS        | サブルーチンからの復帰 |
| BEQ/BNE    | 条件分岐               |
| SEI/CLI    | IRQの無効化/有効化     |

---

## 7. アドレッシングモード（代表例）

| モード       | 例             | 備考           |
| ------------ | -------------- | -------------- |
| イミディエイト | `LDA #$01`     | 定数           |
| ゼロページ   | `LDA $00`      | 高速アクセス   |
| アブソリュート | `LDA $8000`    | フルアドレス   |
| インデックス | `LDA $2000,X`  | テーブル参照   |
| インダイレクト | `JMP ($FFFC)`  | ベクタ参照     |

---

## 8. EEPROM実行用コード作成のポイント

### 重要な考慮点

* 実行時はコードは**読み取り専用**
* セルフモディファイングコードは推奨しない
* ジャンプテーブルや定数はEEPROMに配置
* 変数やスタックはRAMを使用

### ゼロページ変数の例

```asm
counter = $00

        lda #$00
        sta counter
```

---

## 9. タイミングと性能

* EEPROMのアクセス時間はCPUクロックに適合する必要あり
* AT28C256は約1MHzで問題なく動作
* 高速クロックではウェイトステートやROMシャドウイングが必要な場合あり

---

## 10. 例：シンプルなLEDトグル（メモリマップドI/O）

```asm
PORTB = $6000
DDRB  = $6002

        .org $8000
reset:
        sei
        ldx #$FF
        txs

        lda #$FF
        sta DDRB

loop:
        lda #$FF
        sta PORTB
        jsr delay
        lda #$00
        sta PORTB
        jsr delay
        jmp loop
```

---

## 11. アセンブルとプログラミングの流れ

1. ソース（`.asm`）を書く
2. バイナリにアセンブル
3. `$8000`にパディングまたはリロケート
4. T48 / miniproでAT28C256に書き込み
5. EEPROMを挿入しCPUをリセット

---

## 13. よくあるミス

| 問題点                   | 結果                   |
| ------------------------ | ---------------------- |
| ベクタの未設定           | リセット時にCPUが停止  |
| `.org`の誤設定           | コードが実行されない   |
| ROM内でRAMアドレスを使用 | クラッシュ             |
| スタック未初期化         | 未定義動作             |
