# AS6C62256 32K x 8 低消費電力CMOS SRAM仕様書

## 1. 概要

**AS6C62256**は、Alliance Memory製（他社によるセカンドソースあり）の**256Kビット（32K x 8）**低消費電力CMOS静的ランダムアクセスメモリ（SRAM）です。一般的な28ピンSRAMのピン配置に完全対応しており、**6502**、**Z80**、その他の8ビットマイクロプロセッサシステムの読み書きメモリとして広く使用されています。

本デバイスは高速アクセス時間、シンプルな制御ロジック、非常に低いスタンバイ電力消費を特徴としています。

---

## 2. 一般特性

| 特徴               | 説明                             |
| ------------------ | -------------------------------- |
| メモリ容量         | 256Kビット（32KB）               |
| 組織               | 32,768 x 8ビット                 |
| データバス         | 8ビット                         |
| アドレスバス       | 15ビット（A0-A14）              |
| 技術               | CMOS SRAM                      |
| アクセスタイム     | 55 ns / 70 ns（バリアント依存） |
| 動作電圧           | 5 V ± 10%                      |
| スタンバイ電流     | < 1 µA（典型値）                |
| パッケージ種類     | DIP-28、SOJ-28、TSOP-28         |

---

## 3. ピン配置（論理）

### 3.1 アドレスピン（A0-A14）

* 32,768のメモリ位置のいずれかを選択
* 読み書きサイクル中はアドレスが安定している必要あり

### 3.2 データピン（I/O0-I/O7）

* 双方向トライステートデータバス
* 有効でない時は高インピーダンス状態

### 3.3 制御ピン

| ピン | 説明                      |
| ---- | ------------------------- |
| CE#  | チップイネーブル（アクティブロー） |
| OE#  | 出力イネーブル（アクティブロー）   |
| WE#  | 書き込みイネーブル（アクティブロー） |
| VCC  | +5 V電源                  |
| GND  | グランド                  |

---

## 4. メモリ構成

* `$0000`から`$7FFF`までの線形アドレス空間
* 各アドレスは1バイト（8ビット）に対応

```text
アドレス範囲: 0000h - 7FFFh
データ幅:    8ビット
```

---

## 5. 読み出し動作

### 5.1 読み出しサイクル条件

| 信号 | 状態  |
| ---- | ----- |
| CE?  | LOW   |
| OE?  | LOW   |
| WE?  | HIGH  |

* アクセスタイム（tAA）後にデータが有効になる
* CE?とOE?がLOWの間、出力は有効
* CE?またはOE?がHIGHの時、出力は高インピーダンス

---

## 6. 書き込み動作

### 6.1 書き込みサイクル条件

| 信号 | 状態         |
| ---- | ------------ |
| CE?  | LOW          |
| OE?  | HIGHまたはLOW |
| WE?  | LOWパルス    |

* WE?またはCE?の立ち上がりエッジでデータが書き込まれる
* 書き込み期間中はアドレスとデータが安定している必要あり
* 内部書き込み遅延なし（真のSRAM動作）

---

## 7. タイミングメモ（概要）

| パラメータ           | 典型値     |
| -------------------- | ---------- |
| アドレスアクセス (tAA) | 55-70 ns   |
| CE?アクセス (tACE)    | 55-70 ns   |
| OE?アクセス (tOE)     | 25-35 ns   |
| 書き込みサイクル時間  | ≥ 55 ns    |

---

## 8. 電源モード

### 8.1 アクティブモード

* CE? = LOW
* 通常の読み書き動作

### 8.2 スタンバイモード

* CE? = HIGH
* データ保持
* 非常に低い消費電力

---

## 9. リセットおよび電源投入時の動作

* リセットピン不要
* 電源投入時のデータは不定
* VCCが供給されている間のみメモリ内容保持
