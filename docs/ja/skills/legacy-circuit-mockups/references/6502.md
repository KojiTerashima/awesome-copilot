# MOS Technology 6502 マイクロプロセッサ仕様

## 1. 概要

**MOS Technology 6502** は1975年に登場した8ビットマイクロプロセッサです。低コストで効率的な命令セットを持ち、Apple II、Commodore 64、Atari 2600、NES（Ricoh 2A03バリアント）、BBC Microなどの初期のパーソナルコンピュータやゲームコンソールで広く使用されました。

---

## 2. 一般的な特徴

| 特徴           | 説明                     |
| -------------- | ------------------------ |
| データ幅       | 8ビット                  |
| アドレス幅     | 16ビット                 |
| アドレス空間   | 64 KB (0x0000–0xFFFF)    |
| レジスタ       | A, X, Y, SP, PC, P       |
| エンディアン   | リトルエンディアン       |
| クロックスピード | 約1～3 MHz（オリジナルNMOS） |
| 技術           | NMOS                     |

---

## 3. プログラマが見えるレジスタ

### 3.1 アキュムレータ (A)

* 8ビットレジスタ
* 算術、論理、データ転送操作に使用

### 3.2 インデックスレジスタ (X, Y)

* 8ビットレジスタ
* メモリのインデックス、カウンタ、オフセットに使用

### 3.3 スタックポインタ (SP)

* 8ビットレジスタ
* 現在のスタック位置を指す
* スタックはページ `$0100–$01FF` に存在

### 3.4 プログラムカウンタ (PC)

* 16ビットレジスタ
* 次の命令のアドレスを保持

### 3.5 プロセッサステータスレジスタ (P)

| ビット | 名前 | 説明                          |
| ------ | ---- | ----------------------------- |
| 7      | N    | ネガティブ                    |
| 6      | V    | オーバーフロー                |
| 5      | –    | 未使用（プッシュ時は常にセット） |
| 4      | B    | ブレイク                      |
| 3      | D    | 10進モード                    |
| 2      | I    | 割り込み禁止                  |
| 1      | Z    | ゼロ                        |
| 0      | C    | キャリー                      |

---

## 4. メモリマップの慣例

| アドレス範囲   | 用途                     |
| -------------- | ------------------------ |
| `$0000–$00FF`  | ゼロページ               |
| `$0100–$01FF`  | ハードウェアスタック     |
| `$0200–$FFFF`  | プログラム / データ / I/O |

### 4.1 割り込みベクタ

| ベクタ   | アドレス       | 説明                     |
| -------- | -------------- | ------------------------ |
| NMI      | `$FFFA–$FFFB`  | ノンマスカブル割り込み   |
| RESET    | `$FFFC–$FFFD`  | リセットベクタ           |
| IRQ/BRK  | `$FFFE–$FFFF`  | 割り込み要求             |

---

## 5. アドレッシングモード

| モード           | 構文           | 説明                       |
| ---------------- | -------------- | -------------------------- |
| 暗示             | `CLC`          | オペランドが暗示されている |
| アキュムレータ   | `ASL A`        | アキュムレータに作用       |
| イミディエイト   | `LDA #$10`     | 定数値                     |
| ゼロページ       | `LDA $20`      | ゼロページアドレス         |
| ゼロページ,X     | `LDA $20,X`    | ゼロページインデックス付き |
| ゼロページ,Y     | `LDX $20,Y`    | ゼロページインデックス付き |
| アブソリュート   | `LDA $1234`    | 16ビット完全アドレス       |
| アブソリュート,X | `LDA $1234,X`  | インデックス付きアブソリュート |
| アブソリュート,Y | `LDA $1234,Y`  | インデックス付きアブソリュート |
| インダイレクト   | `JMP ($1234)`  | ポインタベースのジャンプ   |
| インデックスドインダイレクト | `LDA ($20,X)` | Xインデックス付きポインタ  |
| インダイレクトインデックス | `LDA ($20),Y` | Yインデックス付きポインタ  |
| 相対             | `BEQ label`    | 分岐オフセット             |

## 6. 命令セット概要

### 6.1 ロード / ストア

* `LDA`, `LDX`, `LDY`
* `STA`, `STX`, `STY`

### 6.2 レジスタ転送

* `TAX`, `TAY`, `TXA`, `TYA`, `TSX`, `TXS`

### 6.3 スタック操作

* `PHA`, `PLA`, `PHP`, `PLP`

### 6.4 算術

* `ADC` – キャリー付き加算
* `SBC` – キャリー付き減算

### 6.5 論理

* `AND`, `ORA`, `EOR`

### 6.6 シフトとローテート

* `ASL`, `LSR`, `ROL`, `ROR`

### 6.7 インクリメント / デクリメント

* `INC`, `INX`, `INY`
* `DEC`, `DEX`, `DEY`

### 6.8 比較

* `CMP`, `CPX`, `CPY`

### 6.9 分岐

* `BEQ`, `BNE`, `BMI`, `BPL`, `BCS`, `BCC`, `BVS`, `BVC`

### 6.10 ジャンプ & サブルーチン

* `JMP`, `JSR`, `RTS`, `RTI`

### 6.11 ステータスフラグ制御

* `CLC`, `SEC`, `CLI`, `SEI`, `CLV`, `CLD`, `SED`

### 6.12 システム制御

* `BRK`, `NOP`

## 7. サイクルタイミング（一般）

* ほとんどの命令は**2～7サイクル**で実行
* 以下の場合は追加サイクルが発生することがある：

  * ページ境界の跨ぎ
  * 分岐が取られた場合

---

## 8. 10進モード

**Dフラグ**がセットされている場合：

* `ADC` と `SBC` は**BCD算術**で動作
* NMOS 6502でのみ有効（CMOS派生品では動作が異なる）

---

## 9. 既知のハードウェアのクセ

* `JMP (addr)` のインダイレクトバグ：ページ境界のラップアラウンド

  * 例：`JMP ($10FF)` は `$10FF` と `$1000` から読み込む
* 乗算や除算の専用命令はなし
* スタックはページ `$01xx` に固定

---

## 10. バリアントと派生品

| バリアント | 備考                                |
| ---------- | ----------------------------------- |
| 6502       | オリジナルNMOS                      |
| 65C02      | CMOS、バグ修正、命令追加           |
| 2A03       | NESバリアント、10進モード無効      |
| 6510       | I/Oポート追加（Commodore 64用）    |

---

## 11. サンプルコード

```asm
        LDX #$00
loop:   INX
        TXA
        STA $0200,X
        CPX #$10
        BNE loop
        BRK
```
