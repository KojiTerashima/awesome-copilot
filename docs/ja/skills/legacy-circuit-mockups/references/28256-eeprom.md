# AT28C256 256K（32K x 8）パラレルEEPROM仕様

## 1. 概要

**AT28C256**は、Atmel（現Microchip）製の不揮発性、電気的に消去・書き込み可能な読み出し専用メモリ（EEPROM）です。**256Kビット**の容量を持ち、**32,768 x 8ビット**の構成で、**6502**、**Z80**などの8ビットマイクロプロセッサシステムで一般的に使用されます。

バイト単位の書き込み操作、高速読み出しアクセス、ソフトウェア制御によるデータ保護をサポートしています。

---

## 2. 一般特性

| 特徴           | 説明                          |
| -------------- | ----------------------------- |
| メモリ容量     | 256Kビット（32KB）            |
| 構成           | 32,768 x 8ビット              |
| データバス     | 8ビット                       |
| アドレスバス   | 15ビット（A0-A14）            |
| 技術           | EEPROM                       |
| 耐久性         | ≥ 100,000書き込みサイクル    |
| データ保持期間 | ≥ 10年                       |
| アクセスタイム | 150-250 ns（バリアント依存） |
| パッケージ種別 | DIP-28、PLCC-32、TSOP        |

---

## 3. ピン配置（論理）

### 3.1 アドレスピン（A0-A14）

* 32,768のメモリ位置のいずれかを選択

### 3.2 データピン（I/O0-I/O7）

* 双方向トライステートデータバス
* 読み出しサイクル中に有効な出力

### 3.3 制御ピン

| ピン | 説明                      |
| ---- | ------------------------- |
| CE   | チップイネーブル（アクティブロー） |
| OE   | 出力イネーブル（アクティブロー）   |
| WE   | 書き込みイネーブル（アクティブロー） |
| VCC  | +5V電源                   |
| GND  | グランド                  |

---

## 4. メモリ構成

* `$0000`から`$7FFF`までの線形アドレス空間
* 各アドレスは1バイト（8ビット）に対応

```text
アドレス範囲: 0000h - 7FFFh
データ幅:    8ビット
```

---

## 5. 読み出し動作

### 5.1 読み出しサイクル条件

| 信号 | 状態  |
| ---- | ------ |
| CE   | LOW    |
| OE   | LOW    |
| WE   | HIGH   |

* アクセスタイム後にI/Oピンにデータが現れる
* CEとOEがアサートされている間、出力は有効
* CEまたはOEがHIGHのとき、出力は高インピーダンス

---

## 6. 書き込み動作

### 6.1 バイト書き込みサイクル

| 信号 | 状態       |
| ---- | ---------- |
| CE   | LOW        |
| OE   | HIGH       |
| WE   | LOWパルス  |

* WEのLOWパルス中はアドレスとデータが安定している必要あり
* 内部書き込みサイクル時間は最大約10ms
* デバイスは自動的に消去後書き込みを行う

---

## 7. ソフトウェアデータ保護（SDP）

AT28C256は誤書き込み防止のためのオプション機能**ソフトウェアデータ保護**を備えています。

### 7.1 SDP有効化シーケンス

```text
アドレス$5555に$AAを書き込む
アドレス$2AAAに$55を書き込む
アドレス$5555に$A0を書き込む
```

### 7.2 SDP無効化シーケンス

```text
アドレス$5555に$AAを書き込む
アドレス$2AAAに$55を書き込む
アドレス$5555に$80を書き込む
アドレス$5555に$AAを書き込む
アドレス$2AAAに$55を書き込む
アドレス$5555に$20を書き込む
```

---

## 8. 書き込みサイクルタイミング注意事項

* 書き込みは内部でタイミング制御され、外部ポーリングは不要
* 書き込み中の読み出しは未定義データを返す
* 書き込み中は追加の書き込み要求を無視

---

## 9. データポーリング（オプション）

* 書き込み中にI/O7を監視可能
* I/O7が書き込みデータと一致したら書き込み完了

---

## 10. リセットおよび電源動作

* 明示的なリセットピンはなし
* 電源投入・遮断時は書き込み禁止
* CEとOEがアサートされるまで出力は高インピーダンス

---

## 11. 典型的なシステム統合例（6502の場合）

```text
アドレス範囲: $8000 - $FFFF
A15はチップセレクトに使用
OE  読み出し/書き込み？
WE  反転読み出し/書き込み？
```
