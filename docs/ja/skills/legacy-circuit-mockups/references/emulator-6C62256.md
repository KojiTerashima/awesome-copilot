# AS6C62256（32K x 8 SRAM）エミュレーション仕様

6502系エミュレータ、SBCシミュレータ、メモリサブシステムモデリングに適した、**AS6C62256 / 62256ファミリー静的RAMのエミュレーション**に関する技術的Markdown仕様。

---

## 1. 適用範囲

本書は以下のエミュレーションの機能動作を規定する：

* Alliance Memory **AS6C62256**
* 互換性のある **62256（32K x 8）SRAM** デバイス

対象外：

* アナログ電気的タイミングマージン
* バス競合および信号の立ち上がり/立ち下がり時間
* 消費電力特性

---

## 2. チップ概要

### コア特性

| 特徴           | 値                   |
| -------------- | -------------------- |
| メモリタイプ   | 静的RAM（SRAM）      |
| 容量           | 32,768バイト（32KB） |
| データ幅       | 8ビット              |
| アドレス幅     | 15ビット（A0-A14）   |
| アクセスタイプ | 非同期               |
| 電源電圧       | 5V（標準）           |

---

## 3. 外部信号（論理モデル）

| 信号   | 方向   | 用途                      |
| ------ | ------ | ------------------------- |
| A0-A14 | 入力   | アドレスバス              |
| D0-D7  | 入出力 | データバス                |
| CE#    | 入力   | チップイネーブル（アクティブロー） |
| OE#    | 入力   | 出力イネーブル（アクティブロー）   |
| WE#    | 入力   | 書き込みイネーブル（アクティブロー） |

> `#` はアクティブロー信号を示す。

---

## 4. アドレス空間マッピング

* アドレス範囲：`0x0000-0x7FFF`
* アドレス線は1バイト単位で選択

### 典型的な6502システムのマッピング例

| CPUアドレス範囲 | デバイス          |
| --------------- | ----------------- |
| `$0000-$7FFF`   | AS6C62256 SRAM    |
| `$8000-$FFFF`   | ROM / EEPROM      |

---

## 5. 読み書き動作

### 読み出しサイクル（論理）

条件：

* `CE# = 0`
* `OE# = 0`
* `WE# = 1`

動作：

```text
D[7:0]  memory[A]
```

`OE# = 1` または `CE# = 1` の場合、データバスは**高インピーダンス**。

---

### 書き込みサイクル（論理）

条件：

* `CE# = 0`
* `WE# = 0`

動作：

```text
memory[A]  D[7:0]
```

* 書き込み時は `OE#` は無視される
* 書き込みは有効なWE#で行われる

---

## 6. 制御信号の優先順位

| CE# | WE# | OE# | 結果             |
| --- | --- | --- | ---------------- |
| 1   | X   | X   | 無効（Hi-Z）     |
| 0   | 0   | X   | 書き込み         |
| 0   | 1   | 0   | 読み出し         |
| 0   | 1   | 1   | Hi-Z             |

---

## 7. エミュレータインターフェース要件

エミュレータは以下を公開する必要がある：

```text
read(address)  -> byte
write(address, byte)
```

内部ストレージ：

```text
uint8_t ram[32768]
```

アドレスマスク：

```text
address = address & 0x7FFF
```

---

## 8. タイミングモデル（抽象化）

### エミュレーションレベル

| レベル           | 説明                      |
| ---------------- | ------------------------- |
| 機能的           | 即時アクセス              |
| サイクルベース   | CPUサイクル単位のアクセス |
| サイクルアキュレート | イネーブル遷移を忠実に再現 |

ほとんどのシステムでは**機能的エミュレーション**で十分。

---

## 9. 電源とデータ保持

* SRAMの内容は電源供給中は保持される
* エミュレータは明示的にリセットされるまで内容を保持すること

### リセット動作

* リセット時に**自動クリアは行わない**
* 初期化されない限りメモリ内容は未定義

---

## 10. バス競合とHi-Zモデリング（オプション）

高度なオプション動作：

* SRAMがデータバスを駆動しているか追跡
* 不正な同時書き込みを検出

ほとんどのエミュレータはHi-Z状態を無視してよい。

---

## 11. エラー条件

| 条件                 | エミュレータの対応               |
| -------------------- | ------------------------------- |
| 範囲外アドレス       | マスクまたは無視                |
| 無効時の読み出し     | 最後のバス値または0xFFを返す    |
| 無効時の書き込み     | 書き込みを無視                  |

---

## 12. 6502エミュレータとの統合

```text
CPUメモリアクセス
  アドレスデコード
  SRAM範囲内なら：
      AS6C62256.read/write
```

* SRAMアクセスは通常シングルサイクル
* ウェイトステート不要

---

## 13. テストと検証

### 基本テスト

* 書き込み/読み出しパターン
* 境界アドレス（$0000, $7FFF）
* ランダムメモリテスト

### 検証チェックリスト

* 書き込みが保持されること
* 読み出しが正しい値を返すこと
* アドレスのラップが正しいこと

---

## 14. よくある間違い

| 間違い               | 結果                          |
| -------------------- | ----------------------------- |
| リセット時にRAMをクリア | ソフトウェアの前提を破壊       |
| アドレスマスクの誤り  | メモリのミラーリングエラー     |
| ROMとして扱う         | 書き込みが無視される           |
