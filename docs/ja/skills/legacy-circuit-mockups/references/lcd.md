# DFRobot FIT0127 LCD文字表示仕様

## 1. 概要

**DFRobot FIT0127**は、組み込みシステムやホビープロジェクトで一般的に使用される**HD44780互換の文字LCDモジュール**のファミリーです。これらのディスプレイはドットマトリックス文字ジェネレーターを使用して英数字を表示し、8ビットおよび4ビットのパラレルインターフェースの両方をサポートします。

FIT0127モジュールは、**6502**、**AVR**、**PIC**、**Arduino**プラットフォームなどのマイクロコントローラーや8ビットCPUと組み合わせて使用されることが多いです。

---

## 2. 一般的な特性

| 特徴               | 説明                                               |
| ------------------ | -------------------------------------------------- |
| 表示タイプ         | 文字LCD（STN、黄緑色バックライトが一般的）         |
| コントローラー     | HD44780または互換                                     |
| インターフェース   | パラレル（4ビットまたは8ビット）                     |
| 文字サイズ         | 5 x 8ドットマトリックス                              |
| 動作電圧           | 5 Vロジック（一部バリアントは3.3 V対応）             |
| バックライト       | LED（別電源ピン）                                   |
| 視認モード         | 透過反射型                                           |

---

## 3. 表示バリエーション

FIT0127は一般的に**16x2文字LCDモジュール**を指します。

| バリアント | 文字数           |
| ---------- | ---------------- |
| FIT0127    | 16列 x 2行       |

## 6. インターフェース信号

### 6.1 RS（レジスタ選択）

| RS | 機能                 |
| -- | -------------------- |
| 0  | 命令レジスタ         |
| 1  | データレジスタ       |

### 6.2 R/W

| R/W | 操作               |
| --- | ------------------ |
| 0   | LCDへの書き込み    |
| 1   | LCDからの読み出し  |

### 6.3 イネーブル（E）

* データはEの**立ち下がりエッジ**でラッチされる
* 各転送ごとにEをHIGHからLOWへパルスする必要がある

---

## 7. データバス動作

### 7.1 8ビットモード

* D0-D7を使用
* 高速動作

### 7.2 4ビットモード

* D4-D7のみ使用
* データは2つのニブル（上位ニブルが先）で転送
* I/Oピンを節約可能

---

## 8. 内部メモリマップ

### 8.1 DDRAM（表示データRAM）

| アドレス      | 表示位置           |
| ------------: | ------------------ |
| 0x00-0x0F    | 1行目、1列目〜16列目 |
| 0x40-0x4F    | 2行目、1列目〜16列目 |

### 8.2 CGRAM（文字生成RAM）

* 最大**8つのカスタム文字**をサポート
* 各文字は8バイト使用

---

## 9. 命令セット（概要）

| 命令       | 説明                   |
| ---------- | ---------------------- |
| 0x01       | 表示クリア             |
| 0x02       | ホームポジションへ移動 |
| 0x04-0x07  | エントリーモード設定   |
| 0x08-0x0F  | 表示ON/OFF制御         |
| 0x10-0x1F  | カーソル/表示シフト    |
| 0x20-0x3F  | 機能設定               |
| 0x40-0x7F  | CGRAMアドレス設定      |
| 0x80-0xFF  | DDRAMアドレス設定      |

---

## 12. 典型的なシステム統合例（6502の場合）

```text
RS   VIA出力
E    VIA出力
D4-D7  VIAポートB
R/W  グランド接続（書き込み専用）
```

## 13. コントラストとバックライト制御

* VOピンのポテンショメーターでコントラスト調整
* バックライトは直列抵抗が必要な場合あり
* 外部制御によるPWM調光対応可能
