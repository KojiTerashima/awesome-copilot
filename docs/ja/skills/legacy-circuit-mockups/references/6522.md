# MOSテクノロジー 6522 多目的インターフェースアダプタ (VIA)

## 1. 概要

**MOSテクノロジー 6522 VIA**は、6502ファミリーのマイクロプロセッサと外部周辺機器を接続するために設計された汎用I/Oコントローラです。1970年代半ばに登場し、パラレルI/Oポート、タイマー、シフトレジスタサポート、割り込み処理を提供します。6522は、コモドールPET、VIC-20、Apple II、BBC Micro、そして多くの6502ベースの組み込み設計で広く使用されています。

---

## 2. 一般的な特徴

| 特徴           | 説明                             |
| -------------- | -------------------------------- |
| データ幅       | 8ビット                          |
| アドレッシング | メモリマップドI/O               |
| レジスタ数     | 16（4ビットのレジスタ選択）     |
| I/Oポート      | 2つの8ビットポート（ポートA、ポートB） |
| タイマー       | 2つの16ビットタイマー           |
| シフトレジスタ | 8ビットシリアルI/O              |
| 割り込み       | マスク可能、複数ソース          |
| クロック       | システムクロック（φ2）          |

---

## 3. ピン機能（論理）

### 3.1 ポートA (PA0-PA7)

* 8ビット双方向パラレルI/O
* CA1 / CA2によるハンドシェイクサポート

### 3.2 ポートB (PB0-PB7)

* 8ビット双方向パラレルI/O
* CB1 / CB2によるハンドシェイクサポート
* PB6およびPB7はタイマー1によって制御可能

### 3.3 制御ピン

| ピン       | 説明                                |
| ---------- | ----------------------------------- |
| CA1 / CB1 | 割り込み対応制御入力                 |
| CA2 / CB2 | ハンドシェイク / パルス / 割り込みピン |
| IRQ       | 割り込み要求出力（アクティブロー）  |
| RESET     | リセット入力                        |

---

## 4. レジスタマップ

レジスタは4本のアドレス線（RS0-RS3）で選択されます。ベースアドレスはシステム定義です。

| オフセット | レジスタ    | 説明                               |
| ---------: | ----------- | ---------------------------------- |
|       $0   | ORB         | 出力レジスタB                     |
|       $1   | ORA / IRB   | 出力レジスタA / 入力レジスタB     |
|       $2   | DDRB        | データ方向レジスタB               |
|       $3   | DDRA        | データ方向レジスタA               |
|       $4   | T1C-L       | タイマー1カウンタ下位             |
|       $5   | T1C-H       | タイマー1カウンタ上位             |
|       $6   | T1L-L       | タイマー1ラッチ下位               |
|       $7   | T1L-H       | タイマー1ラッチ上位               |
|       $8   | T2C-L       | タイマー2カウンタ下位             |
|       $9   | T2C-H       | タイマー2カウンタ上位             |
|       $A   | SR          | シフトレジスタ                   |
|       $B   | ACR         | 補助制御レジスタ                 |
|       $C   | PCR         | 周辺制御レジスタ                 |
|       $D   | IFR         | 割り込みフラグレジスタ           |
|       $E   | IER         | 割り込み許可レジスタ             |
|       $F   | ORA / IRA   | 出力レジスタA / 入力レジスタA   |

---

## 5. データ方向レジスタ (DDRA / DDRB)

各ビットは対応するポートピンの方向を制御します：

* `0` = 入力
* `1` = 出力

```text
DDRBビット = 1 → PBxは出力
DDRBビット = 0 → PBxは入力
```

---

## 6. タイマー

### 6.1 タイマー1 (T1)

* 16ビットダウンカウンタ
* ワンショットまたはフリーランニングモードで動作可能
* タイムアウト時にPB7をトグル可能
* 割り込みを生成

### 6.2 タイマー2 (T2)

* 16ビットダウンカウンタ
* PB6でのパルスカウントをサポート
* ワンショット動作のみ

---

## 7. シフトレジスタ (SR)

* 8ビットシフトレジスタ
* データのシフトインまたはシフトアウトが可能
* クロックソースはACRで選択可能
* シリアル通信やキーボードスキャンによく使用される

---

## 8. 制御レジスタ

### 8.1 補助制御レジスタ (ACR)

| ビット | 機能                              |
| ------:| --------------------------------- |
|      7 | タイマー1制御（PB7出力）          |
|      6 | タイマー1モード（フリーラン / ワンショット） |
|      5 | タイマー2制御                    |
|      4 | シフトレジスタモード             |
|      3 | シフトレジスタクロックソース     |
|      2 | ポートBラッチ                   |
|      1 | ポートAラッチ                   |
|      0 | 未使用                          |

### 8.2 周辺制御レジスタ (PCR)

CA1、CA2、CB1、CB2の動作を制御：

* 入力/出力モード
* アクティブエッジ選択
* パルスまたはハンドシェイクモード

---

## 9. 割り込みシステム

### 9.1 割り込みフラグレジスタ (IFR)

| ビット | ソース                             |
| ------:| ---------------------------------- |
|      7 | IRQ状態（有効な割り込みがあれば） |
|      6 | タイマー1                        |
|      5 | タイマー2                        |
|      4 | CB1                             |
|      3 | CB2                             |
|      2 | シフトレジスタ                 |
|      1 | CA1                             |
|      0 | CA2                             |

### 9.2 割り込み許可レジスタ (IER)

* ビット7はセット/クリアモードを決定：

  * `1` = ビットをセット
  * `0` = ビットをクリア

```text
$80を書き込み | マスク → 割り込み有効化
$00を書き込み | マスク → 割り込み無効化
```

---

## 10. リセット動作

リセット時：

* 全てのDDRビットはクリア（ポートはデフォルトで入力）
* タイマー停止
* シフトレジスタ無効化
* 割り込み無効化

---

## 11. タイミング注意点

* VIAレジスタはφ2に同期してアクセスされる
* タイマーカウンタはφ2サイクルごとにデクリメント
* 一部の操作はレジスタの読み書き時に副作用あり

---

## 12. 一般的な使用例

* キーボードおよびジョイスティックインターフェース
* パラレルプリンタインターフェース
* タイマーおよびイベントカウント
* 簡易シリアル通信
* 汎用GPIO拡張
