# T48 ユニバーサルEEPROM / フラッシュプログラマ仕様

## 1. 概要

**T48ユニバーサルプログラマ**（**TL866-3G / TL866II Plus後継機**としても販売）は、USB接続のデバイスで、幅広い**EEPROM、フラッシュ、EPROM、GAL、マイクロコントローラデバイス**の**読み取り、プログラム、検証**に使用されます。主に**レトロコンピューティング**、**ファームウェア開発**、**電子機器修理**のワークフローで利用されています。

T48はTL866シリーズの現代的な後継機で、対応デバイスの拡充とソフトウェア互換性の向上を実現しています。

---

## 2. 一般的な特徴

| 特徴               | 説明                              |
| ------------------ | --------------------------------- |
| プログラマタイプ   | ユニバーサルデバイスプログラマ    |
| インターフェース   | USB 2.0                          |
| ソケット           | ZIF-48                           |
| 対応デバイス       | EEPROM、フラッシュ、EPROM、GAL、MCU |
| プログラミング電圧 | 内部生成                         |
| ホストOS           | Windows、Linux（オープンソースツール対応） |
| 検証               | 書き込み後読み取り、チェックサム |

---

## 3. 物理的説明

### 3.1 ZIFソケット

* **48ピンゼロ挿入力（ZIF）**ソケット
* DIPパッケージを直接サポート
* PLCC、SOP、TSOPはアダプタ経由で対応

### 3.2 インジケータと操作部

| 項目           | 説明                         |
| -------------- | ---------------------------- |
| ステータスLED  | 電源 / 動作表示              |
| ZIFレバー      | ICをソケットに固定           |
| USBコネクタ    | ホスト接続および電源供給     |

---

## 4. 対応デバイスカテゴリ

### 4.1 メモリデバイス

* 27xxx EPROM
* 28xxx EEPROM（例：AT28C256）
* 29xxx フラッシュメモリ
* シリアルEEPROM（アダプタ使用）

### 4.2 プログラマブルロジック

* GAL16V8、GAL22V10（読み書き検証対応）

### 4.3 マイクロコントローラ（限定的）

* 一部のPIC、AVR、8051ファミリーデバイス
* 電圧およびピン配置によりプログラミング対応可否が異なる

---

## 5. 電気的能力

| パラメータ     | 説明                                  |
| -------------- | ------------------------------------- |
| VCC範囲        | 1.8 V - 6.5 V（デバイス依存）         |
| VPP            | 内部生成、デバイス固有               |
| I/O保護        | 過電流および短絡保護                   |

---

## 6. プログラミング操作

### 6.1 共通操作

* デバイス識別
* ブランクチェック
* 読み取り
* プログラム（書き込み）
* 検証
* 消去（フラッシュ/EPROM）

### 6.2 検証モード

* バイト単位比較
* チェックサム / CRC検証

---

## 7. ソフトウェアサポート

### 7.1 公式ソフトウェア

* WindowsベースのGUI
* ピンマッピング付きデバイスデータベース
* 自動電圧およびタイミング制御

### 7.2 オープンソースツール

| ツール      | 備考                              |
| ----------- | --------------------------------- |
| `minipro`   | Linux / macOS / Windows CLIツール |
| libusb      | USB通信バックエンド               |

例:

```bash
minipro -p AT28C256 -w rom.bin
```

---

## 8. デバイス挿入とピンマッピング

* **ピン1マーカー**でデバイスの向きを示す
* 多くのデバイスはZIFソケットの**左下揃え**を使用
* ソフトウェアは正しい挿入図を表示

---

## 9. 典型的なワークフロー（EEPROM例）

1. デバイスタイプ選択（例：AT28C256）
2. チップをZIFソケットに挿入
3. ブランクチェック実行
4. バイナリイメージを読み込み
5. デバイスにプログラム
6. 書き込み内容を検証

---

## 10. 電源および安全上の注意

* プログラマはUSB経由で完全に給電
* プログラミング中はICの挿抜禁止
* 非DIPパッケージはアダプタを使用

---

## 11. 制限事項

* すべてのマイクロコントローラに対応しているわけではない
* 高電圧EPROMは特定のアダプタが必要な場合あり
* インサーキットプログラミング（ISP）には非対応

---

## 12. 一般的な使用例

* 6502 SBC用EEPROMのプログラミング
* レトロシステム用ROMイメージのフラッシュ
* レガシーEPROMの読み取りおよびバックアップ
* GALロジック開発
