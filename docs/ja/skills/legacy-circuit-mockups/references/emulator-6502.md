# 6502 CPU エミュレーション仕様

MOS Technology 6502 CPUファミリーの**エミュレーション**に関する技術的Markdown仕様書であり、ソフトウェアエミュレータ、教育ツール、テストフレームワーク、レトロコンピューティングプロジェクトに適しています。

---

## 1. 適用範囲

本仕様は以下のエミュレーション機能要件を記述します：

* MOS 6502
* WDC 65C02（明記されている場合）

対象外：

* サイクル単位の正確なアナログ動作
* 物理的なバス競合
* 非公開のシリコン欠陥（明示的に実装しない限り）

---

## 2. CPU概要

### コア特性

| 特徴         | 値             |
| ------------ | -------------- |
| データ幅     | 8ビット        |
| アドレス幅   | 16ビット       |
| アドレス空間 | 64 KB          |
| エンディアン | リトルエンディアン |
| クロック     | 単相           |

---

## 3. レジスタ

| レジスタ | サイズ   | 説明                      |
| -------- | -------- | ------------------------- |
| A        | 8ビット  | アキュムレータ            |
| X        | 8ビット  | インデックスレジスタ      |
| Y        | 8ビット  | インデックスレジスタ      |
| SP       | 8ビット  | スタックポインタ（ページ $01xx） |
| PC       | 16ビット | プログラムカウンタ        |
| P        | 8ビット  | プロセッサステータスフラグ |

### ステータスフラグ (P)

| ビット | 名前 | 意味                          |
| ------ | ---- | ----------------------------- |
| 7      | N    | ネガティブ                    |
| 6      | V    | オーバーフロー                |
| 5      | -    | 未使用（プッシュ時は常に1）  |
| 4      | B    | ブレーク                     |
| 3      | D    | 10進モード                   |
| 2      | I    | IRQ無効                      |
| 1      | Z    | ゼロ                        |
| 0      | C    | キャリー                    |

---

## 4. メモリモデル

### アドレッシング

* 16ビットアドレスバス (`$0000-$FFFF`)
* バイト単位アドレス指定可能

### 必須エミュレータインターフェース

```text
read(address)  -> byte
write(address, byte)
```

### スタック動作

* スタックベース：`$0100`
* プッシュ：`write($0100 + SP, value); SP--`
* プル：`SP++; value = read($0100 + SP)`

---

## 5. リセットと割り込み処理

### リセットシーケンス

1. `I = 1` をセット
2. `SP = $FD` をセット
3. `D` をクリア
4. `$FFFC-$FFFD` から `PC` をロード

### 割り込みベクタ

| 割り込み | ベクタアドレス  |
| -------- | --------------- |
| NMI      | `$FFFA-$FFFB`   |
| RESET    | `$FFFC-$FFFD`   |
| IRQ/BRK  | `$FFFE-$FFFF`   |

---

## 6. 命令フェッチ・デコード・実行サイクル

### 実行ループ（概念的）

```text
opcode = read(PC++)
decode opcode
fetch operands
execute instruction
update flags
increment cycles
```

## 7. アドレッシングモード

| モード             | 例             | 備考                     |
| ------------------ | -------------- | ------------------------ |
| イミディエイト     | `LDA #$10`     | 定数                     |
| ゼロページ         | `LDA $20`      | $00FFでラップ            |
| アブソリュート     | `LDA $2000`    | フルアドレス             |
| インデックス付き   | `LDA $2000,X`  | ページ境界ペナルティあり |
| インダイレクト     | `JMP ($FFFC)`  | ページラップバグあり     |
| インデックスドインダイレクト | `LDA ($20,X)` | ゼロページインデックス   |
| インダイレクトインデックス | `LDA ($20),Y` | ゼロページポインタ       |

## 8. 命令セット要件

### カテゴリ

* ロード/ストア
* 算術（ADC、SBC）
* 論理（AND、ORA、EOR）
* シフト＆ローテート
* 分岐
* スタック操作
* システム制御

### 10進モード（NMOS 6502）

* `ADC` と `SBC` に適用
* `D = 1` の場合BCD算術を使用

## 9. フラグ動作ルール

| 命令タイプ | 影響を受けるフラグ |
| ---------- | ------------------ |
| ロード系   | N, Z               |
| ADC/SBC    | N, V, Z, C         |
| CMP/CPX/CPY| N, Z, C            |
| INC/DEC    | N, Z               |
| シフト系   | N, Z, C            |

---

## 10. サイクルカウント

### サイクル精度レベル

| レベル               | 説明                   |
| -------------------- | ---------------------- |
| 機能的               | 正しい結果のみ         |
| 命令単位正確         | 固定サイクル数         |
| サイクル単位正確     | ページ越えペナルティ含む |

### ページ境界ペナルティ

* 分岐成功時：+1サイクル
* 分岐がページを跨ぐ場合：+2サイクル
* インデックス付きロードがページを跨ぐ場合：+1サイクル

---

## 11. 既知のハードウェア特性（NMOS 6502）

| 特性               | 説明                            |
| ------------------ | ------------------------------- |
| JMPインダイレクトバグ | ページ境界で上位バイトがラップ  |
| BRKはBフラグをセット | プッシュ時のみ                  |
| 未使用フラグビット   | 常に1として読み取られる          |

---

## 12. 非合法/非公開命令（オプション）

* 多くの命令は複合動作を行う
* シリコンリビジョンにより動作が異なる
* 無効化するか明示的に有効化すべき

---

## 13. タイミングとクロック

* 1命令は複数クロックで実行
* エミュレータはホストのティック単位で命令を実行可能
* I/Oタイミング用にサイクルカウンタが必要

---

## 14. 周辺機器との統合

### メモリマップドI/O

```text
if address in IO range:
    delegate to device
```

例：

* 6522 VIA
* UART
* ビデオハードウェア
