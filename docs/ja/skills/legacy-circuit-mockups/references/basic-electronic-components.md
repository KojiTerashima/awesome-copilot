# 基本的な電子部品

このドキュメントでは、抵抗器、コンデンサ、ボタン、スイッチの4つの基本的な電子部品について、一般的な値、公式、種類を含めて説明します。

---

## 1. 抵抗器 (R)

抵抗器は電流の流れを制限し、エネルギーを熱として消散します。

### よく使われる公式

* **オームの法則:** $V = I \times R$（電圧 = 電流 × 抵抗）
* **直列抵抗:** $R_{total} = R_1 + R_2 + ... + R_n$
* **並列抵抗:** $\frac{1}{R_{total}} = \frac{1}{R_1} + \frac{1}{R_2} + ... + \frac{1}{R_n}$

### 一般的な値（E12/E24シリーズ - 5%許容差）

値は10のべき乗で掛けられます（例：10$\Omega$, 100$\Omega$, 1k$\Omega$, 10k$\Omega$, 100k$\Omega$, 1M$\Omega$）：
**1.0, 1.1, 1.2, 1.3, 1.5, 1.6, 1.8, 2.0, 2.2, 2.4, 2.7, 3.0, 3.3, 3.6, 3.9, 4.3, 4.7, 5.1, 5.6, 6.2, 6.8, 7.5, 8.2, 9.1**

---

## 2. コンデンサ (C)

コンデンサは電気的な電荷を電界内に蓄えます。

### よく使われる公式

* **静電容量:** $C = \frac{Q}{V}$（電荷 / 電圧）
* **電流:** $i = C \frac{dV}{dt}$
* **並列静電容量:** $C_{total} = C_1 + C_2 + ... + C_n$
* **直列静電容量:** $\frac{1}{C_{total}} = \frac{1}{C_1} + \frac{1}{C_2} + ... + \frac{1}{C_n}$
* **蓄えられたエネルギー:** $W = \frac{1}{2} C V^2$

### 一般的な値

* **セラミック（ピコファラッド/ナノファラッド）:** 10pF, 22pF, 100pF, 1nF, 10nF, 100nF（しばしば「104」と表記）
* **電解コンデンサ（マイクロファラッド）:** 1µF, 10µF, 22µF, 47µF, 100µF, 220µF, 470µF, 1000µF

---

## 3. ボタン（プッシュボタン）

押されたときだけ回路を閉じる一時的なスイッチです。

### 一般的な種類

* **通常開（NO）:** 押すまで回路は開（オフ）
* **通常閉（NC）:** 押すまで回路は閉（オン）
* **タクタイルスイッチ:** 小型で基板実装用の標準的なボタン

---

## 4. スイッチ (SW)

回路を切断または接続し、切り替えた状態を保持する電気機械的な装置です。

### 一般的な種類

* **SPST:** シングルポール・シングルスロー（オン/オフ）
* **SPDT:** シングルポール・ダブルスロー（2つの経路間の切り替え）
* **DPST/DPDT:** ダブルポールのバリエーション（2つの独立した回路を同時に制御）
* **DIPスイッチ:** 基板用の小型スイッチの配列

## クイックリファレンスまとめ表

| 部品 | 記号（参照） | 主要公式 | 主な用途 |
| :--- | :--- | :--- | :--- |
| **抵抗器** | ジグザグ / ボックス | $V=IR$ | 電流制限、分圧 |
| **コンデンサ** | 2本の平行線 | $i=C \frac{dV}{dt}$ | フィルタリング、タイミング、結合 |
| **ボタン** | 一時接点 | 該当なし | ユーザー入力（一時的） |
| **スイッチ** | トグル/レバー | 該当なし | 電源制御、信号経路切替 |
