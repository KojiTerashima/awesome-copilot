# 6522 VIA（多用途インターフェースアダプタ）エミュレーション仕様

**MOS Technology / WDC 6522 VIA**のエミュレーションに関する技術的Markdown仕様書であり、6502ファミリーのエミュレータ、SBCシミュレータ、レトロコンピューティングソフトウェア環境に適しています。

---

## 1. 適用範囲

本書は以下のエミュレーションに必要な機能動作を定義します：

* MOS Technology 6522 VIA
* WDC 65C22 VIA（CMOS版、注記がある場合）

対象外：

* アナログ電気特性
* バス競合および伝播遅延
* 非公開シリコンのレースコンディション

---

## 2. チップ概要

### コア機能

| 機能           | 説明                              |
| -------------- | --------------------------------- |
| I/Oポート      | 2つの8ビット双方向ポート（A、B） |
| タイマー       | 2つのプログラム可能なタイマー     |
| シフトレジスタ | 8ビットシリアルシフトレジスタ     |
| 割り込みシステム | マスク可能で優先順位付き           |
| ハンドシェイク | CA1/CA2、CB1/CB2制御線            |

---

## 3. 外部信号（論理モデル）

| 信号     | 方向     | 用途                      |
| -------- | -------- | ------------------------- |
| PA0-PA7  | 入出力   | ポートA                   |
| PB0-PB7  | 入出力   | ポートB                   |
| CA1, CA2 | 入出力   | 制御線A                   |
| CB1, CB2 | 入出力   | 制御線B                   |
| IRQ      | 出力     | CPUへの割り込み要求       |
| CS1, CS2 | 入力     | チップセレクト           |
| R/W      | 入力     | 読み取り/書き込み         |
| RS0-RS3  | 入力     | レジスタ選択             |

---

## 4. レジスタマップ

レジスタはRS3-RS0で選択されます。

| アドレス | 名前          | R/W | 説明                            |
| -------- | ------------- | --- | ------------------------------- |
| 0        | ORB / IRB     | R/W | 出力/入力レジスタB              |
| 1        | ORA / IRA     | R/W | 出力/入力レジスタA              |
| 2        | DDRB          | R/W | データ方向レジスタB             |
| 3        | DDRA          | R/W | データ方向レジスタA             |
| 4        | T1C-L         | R   | タイマー1カウンタ下位           |
| 5        | T1C-H         | R   | タイマー1カウンタ上位           |
| 6        | T1L-L         | W   | タイマー1ラッチ下位             |
| 7        | T1L-H         | W   | タイマー1ラッチ上位             |
| 8        | T2C-L         | R   | タイマー2カウンタ下位           |
| 9        | T2C-H         | R   | タイマー2カウンタ上位           |
| 10       | SR            | R/W | シフトレジスタ                 |
| 11       | ACR           | R/W | 補助制御レジスタ               |
| 12       | PCR           | R/W | 周辺制御レジスタ               |
| 13       | IFR           | R/W | 割り込みフラグレジスタ         |
| 14       | IER           | R/W | 割り込み許可レジスタ           |
| 15       | ORA（HSなし） | R/W | 出力レジスタA（ハンドシェイクなし） |

---

## 5. データ方向レジスタ

* ビット=1 → 出力
* ビット=0 → 入力

```text
output = ORx & DDRx
input  = external & ~DDRx
```

---

## 6. ポート動作

### 読み取り

* 入力に設定されたビットは入力ピンの値を返す
* 出力に設定されたビットは出力ラッチの値を返す

### 書き込み

* 出力ラッチのみ更新
* 実際のピン値はDDRに依存

---

## 7. タイマー

### タイマー1（T1）

* 16ビットダウンカウンタ
* 割り込み生成可能
* PB7トグルオプションあり

### タイマー2（T2）

* 16ビットダウンカウンタ
* ワンショットまたはパルスカウント（CB1）

### タイマーエミュレーション規則

* CPUサイクルごとに1回減算
* 適切なタイミングでラッチからリロード
* アンダーフロー時に割り込みフラグセット

---

## 8. シフトレジスタ（SR）

ACRで制御されるモード：

* 無効
* CB1クロックでシフトイン
* システムクロックでシフトアウト

エミュレータ要件：

* 8ビットシフト
* 正しいビット順序
* 外部クロック処理オプション

---

## 9. 制御レジスタ

### 補助制御レジスタ（ACR）

制御内容：

* タイマー1モード
* タイマー2モード
* シフトレジスタモード
* PB7動作

### 周辺制御レジスタ（PCR）

制御内容：

* CA1/CB1のエッジ感度
* CA2/CB2のハンドシェイク／パルス／出力モード

---

## 10. 割り込みシステム

### 割り込みフラグレジスタ（IFR）

| ビット | ソース               |
| ------ | -------------------- |
| 0      | CA2                  |
| 1      | CA1                  |
| 2      | シフトレジスタ       |
| 3      | CB2                  |
| 4      | CB1                  |
| 5      | タイマー2            |
| 6      | タイマー1            |
| 7      | 任意の割り込み（論理和） |

### 割り込み許可レジスタ（IER）

* ビット7 = 設定/クリアモード
* ビット0-6 = 個別ソースの許可

### IRQ論理

```text
IRQ = (IFR & IER & 0x7F) != 0
```

---

## 11. ハンドシェイクライン

### CA1 / CB1

* エッジ検出入力
* 割り込みをトリガー

### CA2 / CB2

* 入力または出力
* パルスまたはハンドシェイクモード

エミュレータは：

* ピン状態を追跡
* 設定されたエッジを検出

---

## 12. リセット動作

リセット時：

* DDRx = $00
* ORx = $00
* タイマー停止
* IFRクリア
* IERクリア
* IRQ非アクティブ

---

## 13. 読み書きの副作用

| レジスタ      | 副作用                     |
| ------------- | -------------------------- |
| ORA/ORB       | ハンドシェイクフラグをクリア |
| T1C-H書き込み | タイマー1をロードして開始   |
| IFR書き込み   | 書き込んだビットをクリア     |
| IER書き込み   | 許可ビットを設定またはクリア |

---

## 14. エミュレーションタイミングレベル

| レベル          | 説明                         |
| --------------- | ---------------------------- |
| 機能的           | 正しいレジスタ動作           |
| サイクルベース   | CPUサイクルごとにタイマー進行 |
| サイクル精密     | 実際のVIAタイミングに一致     |

---

## 15. 6502エミュレータとの統合

```text
CPUサイクル → VIAティック → タイマー更新 → IRQ更新
```

* VIAはCPUと同期してクロックされる必要あり
* IRQラインは命令境界でCPUによりサンプリングされる

---

## 16. テストと検証

### 推奨テスト

* VIAタイマーテストROM
* ポート読み書きテスト
* 割り込み優先度テスト

### 検証チェックリスト

* タイマーが正しくカウントする
* IRQが正しくアサートおよびクリアされる
* DDR動作が正しい
* 副作用が実装されている

---

## 17. 違い：6522 vs 65C22（概要）

| 機能           | 6522    | 65C22     |
| -------------- | ------- | --------- |
| 消費電力       | 高い    | 低い      |
| 10進数の問題   | なし    | 修正済み  |
| タイマー精度   | NMOS    | 改良済み  |
