# DFRobot FIT0127 LCD文字表示エミュレーション仕様

## 概要

本書は**DFRobot FIT0127 LCD文字表示モジュールのエミュレーション方法**を規定します。FIT0127は**16x2文字のLCD**で、**HD44780コントローラ互換**、6502やマイコンのブレッドボードシステムでよく使われます。

目的は電気信号のシミュレーションではなく、SBCエミュレータ、ファームウェアテスト、UI可視化のための**機能的正確性**です。

---

## モジュール概要

| 特徴             | 値                      |
| ---------------- | ----------------------- |
| 表示タイプ       | 文字LCD                 |
| 解像度           | 16列 x 2行              |
| コントローラ     | HD44780互換              |
| インターフェース | 8ビットまたは4ビット並列 |
| 文字マトリクス   | 5x8ドット               |
| 電源電圧         | 5V                      |

---

## ピン定義

| ピン | 名称  | 機能               |
| ---- | ----- | ------------------ |
| 1    | GND   | グランド           |
| 2    | VCC   | +5V                |
| 3    | VO    | コントラスト調整   |
| 4    | RS    | レジスタ選択       |
| 5    | R/W   | 読み書き切替       |
| 6    | E     | イネーブル         |
| 7-14 | D0-D7 | データバス         |
| 15   | A     | バックライト +     |
| 16   | K     | バックライト -     |

---

## 論理レジスタ

| RS | レジスタ             |
| -- | -------------------- |
| 0  | 命令レジスタ         |
| 1  | データレジスタ       |

---

## 命令セット（一部）

| コマンド           | コード        | 説明                         |
| ------------------ | ------------- | ---------------------------- |
| 画面クリア         | `0x01`        | DDRAMクリア、カーソルホーム  |
| ホームに戻る       | `0x02`        | カーソルをホーム位置に移動   |
| エントリモード設定 | `0x04-0x07`   | カーソル移動方向             |
| 表示制御           | `0x08-0x0F`   | 表示、カーソル、点滅制御     |
| カーソル/シフト    | `0x10-0x1F`   | カーソルまたは表示のシフト   |
| 機能設定           | `0x20-0x3F`   | データ長、表示行数設定       |
| CGRAMアドレス設定  | `0x40-0x7F`   | カスタム文字設定             |
| DDRAMアドレス設定  | `0x80-0xFF`   | カーソル位置設定             |

---

## 内部メモリモデル

### DDRAM（表示データRAM）

* サイズ：80バイト
* 1行目ベース：`0x00`
* 2行目ベース：`0x40`

エミュレータマッピング：

```text
行0: DDRAM[0x00-0x0F]
行1: DDRAM[0x40-0x4F]
```

### CGRAM（文字生成RAM）

* 最大8つのカスタム文字を格納
* 1文字あたり8バイト

---

## データ書き込みサイクル

書き込みは以下の条件で発生：

```
RS = 1
R/W = 0
E: HIGH から LOWへ
```

### エミュレータ動作

* `E`の立下りエッジでデータをラッチ
* アドレスモードに応じてDDRAMまたはCGRAMに書き込み
* エントリモードに基づきアドレスを自動インクリメントまたはデクリメント

---

## 命令書き込みサイクル

コマンド書き込みは以下の条件で発生：

```
RS = 0
R/W = 0
E: HIGH から LOWへ
```

---

## 読み取りサイクル（任意）

読み取りはホビー用途では稀です。

```
RS = 0または1
R/W = 1
E: HIGH
```

エミュレータは簡略化可能：

* 読み取りを完全無視
* またはビジーフラグ＋アドレスカウンタを返す

---

## ビジーフラグのエミュレーション

### 実機

* ビジーフラグ = D7ビット
* コマンド処理時間は37～1520マイクロ秒

### エミュレータ選択肢

| モード       | 動作               |
| ------------ | ------------------ |
| 簡略化       | 常に準備完了状態   |
| タイムド     | Nサイクルビジー状態 |

推奨デフォルト：**常に準備完了**

---

## 電源投入時状態

リセット時：

* 表示OFF
* カーソルOFF
* DDRAMはクリアまたは未定義
* アドレスカウンタ = 0

エミュレータは：

* DDRAMをクリア
* カーソルを(0,0)に設定
* 表示を有効にする

---

## カーソルと表示モデル

状態変数：

```text
cursor_row
cursor_col
display_on
cursor_on
blink_on
```

書き込み後、エントリモードに従いカーソルが自動移動。

---

## 4ビット vs 8ビットインターフェース

### 8ビットモード

* D0-D7にて1バイト全体を転送

### 4ビットモード

* 上位ニブルを先に送信
* 1バイトあたり2回のイネーブルパルス

エミュレータ簡略化：

* フルバイト書き込みを受け入れ
* ニブルタイミングは無視

---

## 描画モデル（エミュレータUI）

推奨手法：

* 16x2文字バッファを保持
* ASCIIサブセットをレンダリング
* 非対応グリフは代替表示
* 必要に応じてカスタムCGRAM文字も描画

---

## エミュレータAPIモデル

```c
typedef struct {
    uint8_t ddram[80];
    uint8_t cgram[64];
    uint8_t addr;
    bool display_on;
    bool cursor_on;
    bool blink_on;
    uint8_t entry_mode;
} FIT0127_LCD;
```

---

## 6502システムでの一般的な配線

```
VIAポート → LCD D4-D7（4ビットモード）
RS → VIAビット
E  → VIAビット
R/W → GND
```
