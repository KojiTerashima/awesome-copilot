# はんだ付け不要ブレッドボード

電子回路の試作、教育、ホビー開発向けの**一般的なはんだ付け不要ブレッドボード**に関する実用的なMarkdown仕様書およびリファレンス。

---

## 1. 概要

**はんだ付け不要ブレッドボード**は、電子部品をはんだ付けせずに接続できる再利用可能な試作プラットフォームです。内部のスプリングクリップによって接続が行われます。

### 典型的な用途

* 回路の迅速な試作
* 教育用実験室
* ロジックおよびマイコン実験
* 低消費電力のアナログ・デジタル回路

### 不向きな用途

* 高電流（>1A）
* 高電圧（>36V）
* RF / 高周波設計
* 振動が多いまたは恒久的な設置

---

## 2. 物理的構造

### 材料

* ABSまたはポリスチレン製ボディ
* リン青銅またはニッケルメッキのスプリング接点
* 粘着テープ付き（オプション）

### 標準穴ピッチ

* **2.54 mm（0.1インチ）** - DIP ICや標準ヘッダーに対応

### 接点特性

| パラメータ         | 典型値        |
| ------------------ | ------------- |
| 接触抵抗           | 10-50 mΩ      |
| 挿抜回数           | 約5,000回     |
| ワイヤゲージ       | 20-28 AWG     |

---

## 3. 内部電気接続

### ターミナルストリップ（メインエリア）

* **5つの穴が横方向に接続された行**
* 水平方向の接続
* 中央の溝が左右の半分を分離

```
A B C D E | F G H I J
──────────┼──────────
接続済み  | 接続済み
```

### 電源レール

* 両側に縦方向のバス
* 多くは**中央で分割**されている（必ずしも連続していない）
* 通常は**赤（+）**と**青（-）**で表示

```
+  +  +  +  +   （分割されている場合あり）
-  -  -  -  -
```

> ? マルチメーターで必ず導通を確認してください

## 5. 部品の互換性

### 互換性のある部品

* DIP IC（300 mil、600 mil）
* 軸方向抵抗器およびダイオード
* LED
* タクタイルスイッチ
* ジャンパーワイヤー
* ピンヘッダー

### 問題のある部品

| 部品                 | 問題点                     |
| -------------------- | -------------------------- |
| TO-220               | 幅が広すぎて接点に負荷がかかる |
| SMD                  | アダプターが必要           |
| 大型電解コンデンサ   | 機械的ストレスがかかる     |
| 高出力抵抗器         | 発熱が問題                 |

## 7. ベストプラクティス

### 電源配線

* **GNDとVcc**を両側に配線する
* 必要に応じて分割された電源レールをブリッジする
* ICには**0.1µFのセラミックコンデンサ**でデカップリングを行う

### 配線

* 配線は短く整頓する
* 色分けを使用：

  * 赤：Vcc
  * 黒／青：GND
  * 黄／白：信号線

### ICの配置

* DIP ICは**中央の溝をまたぐように配置**
* ピンを無理に押し込まない

---

## 8. よくあるミス

| ミス                           | 結果                 |
| ------------------------------ | -------------------- |
| 電源レールが連続していると誤認 | 電力損失             |
| 長いジャンパーワイヤー         | ノイズ、不安定動作   |
| デカップリングコンデンサなし   | 不安定な動作         |
| 電流制限を超える               | 接点の溶損           |

---

## 9. テストとデバッグ

### 導通チェック

* マルチメーターで電源レールや行の導通を確認する

### 信号品質のヒント

* 以下の用途にはブレッドボードを避ける：

  * 高速クロック
  * ADCの高精度回路
