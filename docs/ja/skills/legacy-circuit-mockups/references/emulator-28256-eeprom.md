# AT28C256 EEPROM エミュレーション仕様

## 概要

本書は、6502ベースのシステムエミュレータにおいて **AT28C256（32KBパラレルEEPROM）** をどのようにエミュレートするかを規定します。目的は、SBCやモニタ、実際のROMイメージに適した*動作精度*であり、単なる汎用ファイルバックストレージではありません。

AT28C256は6502システムで一般的に**ROM**として使用されますが、*電気的に書き込み可能*であり、SRAMとは異なるタイミング動作を持ちます。

---

## チップ概要

| パラメータ       | 値                      |
| ---------------- | ----------------------- |
| 容量             | 32KB（256Kbit）         |
| 組織             | 32,768 x 8              |
| アドレス線       | A0-A14                  |
| データ線         | D0-D7                   |
| 電源電圧         | 5V                      |
| 典型的用途       | ROM / ファームウェア保存 |

---

## ピン定義

| ピン    | 名称          | 機能                     |
| ------- | ------------- | ------------------------ |
| A0-A14  | アドレス     | バイトアドレス           |
| D0-D7   | データ       | データバス               |
| /CE     | チップイネーブル | チップを有効化           |
| /OE     | 出力イネーブル | 出力ドライバを有効化     |
| /WE     | 書き込みイネーブル | 書き込みサイクルを開始   |
| VCC     | +5V          | 電源                     |
| GND     | グランド     | 基準電位                 |

---

## 読み出しサイクル動作

読み出しは以下の条件で発生します：

```
/CE = 0
/OE = 0
/WE = 1
```

### 読み出しルール

* `/OE`がアサートされる前にアドレスは安定している必要がある
* アクセスタイム後にD0-D7にデータが現れる（多くのエミュレータでは無視される）
* `/OE = 1`または`/CE = 1`のとき出力は**ハイインピーダンス**

### エミュレータ動作例

```text
if CE == 0 and OE == 0 and WE == 1:
    data_bus = memory[address]
else:
    data_bus = Z
```

---

## 書き込みサイクル動作

書き込みは以下の条件で発生します：

```
/CE = 0
/WE = 0
```

（書き込み中は通常`/OE`はHIGH）

### 重要なEEPROM特性

* 書き込みは**瞬時ではない**
* 各書き込みは**内部プログラミングサイクル**をトリガーする
* プログラミング中は読み出しが未定義データを返す場合がある

---

## 書き込みタイミングモデル（簡易版）

### 実機ハードウェア

| パラメータ       | 典型値     |
| ---------------- | ---------- |
| バイト書き込み時間 | 約200µs    |
| ページサイズ     | 64バイト   |
| ページ書き込み時間 | 約10ms     |

### エミュレータ簡略化オプション

#### オプションA - 即時書き込み（一般的）

* 書き込みは即座にメモリを更新
* ビジーステートなし
* 初期のエミュレータに推奨

#### オプションB - サイクルベースのビジーステート（高度）

* 「書き込み中」タイマーを追跡
* 書き込み中の読み出しは最後の値または`0xFF`を返す
* サイクル完了まで書き込みは無視される

---

## ページ書き込みエミュレーション（任意）

* ページサイズ：**64バイト**
* タイムアウト前に同一ページ内での書き込みはまとめてコミット
* ページ境界を越えるとページ内でラップ（ハードウェアの特性）

簡略ルール：

```text
page_base = address & 0xFFC0
page_offset = address & 0x003F
```

---

## 書き込み保護動作

一部システムではプログラミング後にEEPROMを**ROM専用**として扱う。

エミュレータは以下をサポート可能：

* 読み出し専用モード（書き込み無視）
* プログラム可能モード（書き込み許可）
* 実行時切り替え（プログラミングジャンパーのシミュレーション）

---

## 電源投入時状態

* EEPROMは内容を保持
* 電源投入時に未定義データはない

エミュレータは：

* イメージファイルから内容をロード
* リセット間でデータを保持

---

## バスコンテンションルール

| 条件               | 動作               |
| ------------------ | ------------------ |
| /CE = 1            | データバス = Z     |
| /OE = 1            | データバス = Z     |
| /WE = 0 かつ /OE = 0 | 未定義（回避推奨） |

エミュレータは：

* 書き込みを優先
* または無効状態をフラグ

## 6502システムにおけるメモリマッピング

一般的な配置：

```
$0000-$7FFF  RAM
$8000-$FFFF  AT28C256 EEPROM
```

### リセットベクタの使用

| ベクタ | アドレス       |
| ------ | -------------- |
| RESET  | $FFFC-$FFFD    |
| NMI    | $FFFA-$FFFB    |
| IRQ    | $FFFE-$FFFF    |

## エミュレータAPIモデル

```c
typedef struct {
    uint8_t memory[32768];
    bool write_enabled;
    bool busy;
    uint32_t busy_cycles;
} AT28C256;
```

### 読み出し

```c
uint8_t eeprom_read(addr);
```

### 書き込み

```c
void eeprom_write(addr, value);
```

## 推奨エミュレータデフォルト設定

| 機能           | 設定         |
| -------------- | ------------ |
| 書き込み遅延   | 無効         |
| ページモード   | 無効         |
| 書き込み保護   | 有効         |
| 永続性         | ファイルバック |

---

## テストチェックリスト

* リセットベクタのフェッチ
* 通常実行時のROM読み出し
* 読み出し専用モードでの書き込み無視
* 正しいアドレスマスキング（15ビット）
* 無効時のバスドライブなし
