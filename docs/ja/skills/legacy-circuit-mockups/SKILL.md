# レガシー回路モックアップ

レトロコンピューティングや電子プロジェクト向けにブレッドボード回路のモックアップや視覚的な回路図を作成するスキルです。このスキルはHTML5 Canvas描画機構を活用し、6502マイクロプロセッサ、555タイマーIC、EEPROM、7400シリーズ論理ゲートなどのヴィンテージ部品を用いたインタラクティブな回路レイアウトを描画します。

## このスキルを使うタイミング

- ユーザーが「ブレッドボードレイアウトを作成してほしい」や「回路をモックアップしてほしい」と依頼したとき
- ユーザーがブレッドボード上の部品配置を視覚化したいとき
- 6502コンピュータの組み立て参考図が必要なとき
- ユーザーが「回路を描いてほしい」や「電子回路の図を作成してほしい」と言ったとき
- 教育用の電子回路ビジュアルを作成したいとき
- Ben Eaterのチュートリアルやレトロコンピューティングプロジェクトに言及したとき
- 555タイマー回路やLEDプロジェクトのモックアップを依頼されたとき
- 部品間の配線接続を視覚化したいとき

## 前提条件

- 同梱のリファレンスファイルから部品のピン配置を理解していること
- ブレッドボードのレイアウト規則（行、列、電源レール）を知っていること

## ステップバイステップの作業手順

### 基本的なLED回路モックアップの作成

1. ブレッドボードの寸法とグリッドを定義する
2. 電源レール接続（+5VとGND）を配置する
3. アノード・カソード方向を指定してLED部品を配置する
4. 電流制限用抵抗を配置する
5. 部品間の配線を描く
6. ラベルや注釈を追加する

### 555タイマー回路の作成

1. NE555 ICをブレッドボードに配置（ピン1-4は左側、5-8は右側）
2. ピン1（GND）をグラウンドレールに接続
3. ピン8（Vcc）を電源レールに接続
4. タイミング用抵抗とコンデンサを追加
5. トリガーとスレッショルドの配線を行う
6. 出力をLEDや他の負荷に接続する

### 6502マイクロプロセッサレイアウトの作成

1. W65C02Sをブレッドボード中央に配置
2. プログラム格納用に28C256 EEPROMを追加
3. 入出力用にW65C22 VIAを配置
4. アドレスデコード用に7400シリーズ論理を追加
5. アドレスバス（A0-A15）を配線
6. データバス（D0-D7）を配線
7. 制御信号（R/W、PHI2、RESB）を接続
8. リセットボタンとクロッククリスタルを追加

## 計算式リファレンス

### 抵抗計算

- **オームの法則:** V = I × R
- **LED電流制限抵抗:** R = (Vcc - Vled) / Iled
- **消費電力:** P = V × I = I² × R

### 555タイマー計算式

**非安定モード（Astable）：**

- 周波数: f = 1.44 / ((R1 + 2×R2) × C)
- ハイ時間: t₁ = 0.693 × (R1 + R2) × C
- ロー時間: t₂ = 0.693 × R2 × C
- デューティ比: D = (R1 + R2) / (R1 + 2×R2) × 100%

**単安定モード（Monostable）：**

- パルス幅: T = 1.1 × R × C

### コンデンサ計算

- 容量性リアクタンス: Xc = 1 / (2πfC)
- 蓄積エネルギー: E = ½ × C × V²

## ビルド例

### ビルド1 — 単一LED回路

**部品:** 赤色LED、220Ω抵抗、ジャンパーワイヤー、電源

**手順:**

1. 黒色ジャンパーワイヤーを電源GNDから行A5に挿入
2. 赤色ジャンパーワイヤーを電源+5Vから行J5に挿入
3. LEDをカソード（短い脚）がGNDに合うように配置
4. 220Ω抵抗を電源とLEDのアノード間に配置

### ビルド2 — 555非安定マルチバイブレータ点滅回路

**部品:** NE555、LED、抵抗（10kΩ、100kΩ）、コンデンサ（10µF）

**手順:**

1. 555 ICを中央チャネルにまたがって配置
2. ピン1をGND、ピン8を+5Vに接続
3. ピン4をピン8に接続してリセット無効化
4. ピン7と+5V間に10kΩ抵抗を接続
5. ピン6とピン7間に100kΩ抵抗を接続
6. ピン6とGND間に10µFコンデンサを接続
7. ピン3（出力）をLED回路に接続

## トラブルシューティング

| 問題 | 解決策 |
|-------|----------|
| LEDが点灯しない | 極性を確認（アノードは+、カソードは-） |
| 回路に電源が入らない | 電源レール接続を確認 |
| ICが動作しない | VCCとGNDのピン接続を確認 |
| 555が発振しない | スレッショルド/トリガーのコンデンサ配線を確認 |
| マイクロプロセッサが停止する | リセット信号（RESB）がリセット後にHIGHになっているか確認 |
