# .NET 用のセマンティック カーネル

ターゲット プロジェクトが C# または別の .NET 言語で記述されている場合は、このリファレンスを使用します。

## 信頼できる情報源

- リポジトリ: <https://github.com/microsoft/semantic-kernel/tree/main/dotnet>
- サンプル: <https://github.com/microsoft/semantic-kernel/tree/main/dotnet/samples>

## .NET 固有のガイダンス

- カーネル操作には `async`/`await` パターンを一貫して使用します。
- 強力な型指定と明示的なインターフェイスを使用して .NET のベスト プラクティスに従います。
- サービスの登録、構成、認証を標準の .NET ホスティング パターンに合わせて維持します。
- 新しい API、プラグイン、またはオーケストレーション パターンを導入する前に、最新の .NET サンプルを確認してください。
