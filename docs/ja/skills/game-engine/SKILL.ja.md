# Game Engine Skill

HTML5 Canvas、WebGL、JavaScript を使って、Web ベースのゲームやゲームエンジンを構築します。このスキルには、Phaser、Three.js、Babylon.js、A-Frame などのフレームワークを用いた 2D/3D ゲーム開発向けのスターターテンプレート、リファレンスドキュメント、段階的なワークフローが含まれます。

## このスキルを使う場面

- Web 技術を使ってゲームエンジンやゲームをゼロから構築するとき
- ゲームループ、物理、当たり判定、レンダリングを実装するとき
- ゲームグラフィックスのために HTML5 Canvas、WebGL、SVG を扱うとき
- ゲーム操作（キーボード、マウス、タッチ、ゲームパッド）を追加するとき
- 2D プラットフォーマー、ブロック崩し系ゲーム、迷路ゲーム、3D 体験を作成するとき
- タイルマップ、スプライト、アニメーションを扱うとき
- Web ゲームにオーディオを追加するとき
- WebRTC や WebSockets でマルチプレイヤー機能を実装するとき
- ゲームのパフォーマンスを最適化するとき
- Web ゲームを公開・配布するとき

## 前提条件

- HTML、CSS、JavaScript の基本知識
- Canvas/WebGL をサポートするモダンな Web ブラウザ
- テキストエディタまたは IDE
- 任意: ビルドツールやローカル開発サーバー用の Node.js

## コアコンセプト

以下の概念は、あらゆる Web ベースゲームエンジンの土台になります。

### ゲームループ

すべてのゲームエンジンは、次を繰り返す連続サイクルであるゲームループを中心に動作します。

1. **入力処理** - キーボード、マウス、タッチ、ゲームパッド入力を読み取る
2. **状態更新** - ゲームオブジェクトの位置、物理、AI、ロジックを更新する
3. **レンダリング** - 現在のゲーム状態を画面に描画する

滑らかでブラウザ最適化された描画のために `requestAnimationFrame` を使います。

### レンダリング

- **Canvas 2D** - 2D ゲーム、スプライトベース描画、タイルマップに最適
- **WebGL** - ハードウェアアクセラレーションによる 3D と高度な 2D 描画
- **SVG** - ベクターベースのグラフィックスで、UI 要素に適している
- **CSS** - DOM ベースのゲーム要素やトランジションに有用

### 物理と当たり判定

- **2D Collision Detection** - AABB、円形、SAT ベースの衝突判定
- **3D Collision Detection** - バウンディングボックス、バウンディングスフィア、レイキャスティング
- **Velocity and Acceleration** - 移動のための基本的なニュートン力学
- **Gravity** - プラットフォーマー向けの一定の下向き加速度

### 操作

- **Keyboard** - 矢印キー、WASD、カスタムキーバインド
- **Mouse** - クリック、移動、FPS 系操作のためのポインターロック
- **Touch** - モバイルのタッチイベントと仮想ジョイスティック
- **Gamepad** - コントローラー対応のための Gamepad API

### オーディオ

- **Web Audio API** - プログラムによる音声生成と空間オーディオ
- **HTML5 Audio** - 音楽や効果音のシンプルな再生

## 段階的ワークフロー

### 基本的な 2D ゲームを作る

1. `<canvas>` 要素を含む HTML ファイルを用意する
2. 2D レンダリングコンテキストを取得する
3. `requestAnimationFrame` を使ってゲームループを実装する
4. 位置、速度、サイズのプロパティを持つゲームオブジェクトを作る
5. プレイヤー操作のためにキーボード/マウス入力を処理する
6. ゲームオブジェクト間の当たり判定を実装する
7. スコア、残機、勝敗条件を追加する
8. 効果音と音楽を追加する

### 3D ゲームを構築する

1. フレームワークを選ぶ（Three.js、Babylon.js、A-Frame、または PlayCanvas）
2. シーン、カメラ、レンダラーを設定する
3. 3D モデルとテクスチャを読み込む、または作成する
4. ライティングとシェーダーを実装する
5. 物理と当たり判定を追加する
6. プレイヤー操作とカメラ移動を実装する
7. オーディオと視覚効果を追加する

### ゲームを公開する

1. アセットを最適化する（画像圧縮、コード最小化）
2. ブラウザとデバイスをまたいでテストする
3. 配布プラットフォームを選ぶ（Web、アプリストア、ゲームポータル）
4. 必要に応じてマネタイズを実装する
5. ゲームコミュニティや SNS で宣伝する

## トラブルシューティング

| Issue | Solution |
|-------|----------|
| Canvas が真っ白になる | コンテキスト取得後、かつゲームループ内で描画メソッドを呼び出しているか確認する |
| ゲーム速度が環境ごとに異なる | 固定値ではなく、更新計算にデルタタイムを使う |
| 当たり判定が安定しない | 連続衝突判定を使うか、高速移動オブジェクトではタイムステップを小さくする |
| 音が再生されない | ブラウザは音声再生前にユーザー操作を必要とするため、クリックハンドラーから再生を開始する |
| パフォーマンスが低い | ブラウザの開発ツールでプロファイルし、ドローコール削減、オブジェクトプーリング、アセットサイズ最適化を行う |
| タッチ操作が反応しない | 既定のタッチ挙動を抑止し、マウスイベントとは別にタッチイベントを処理する |
| WebGL コンテキストが失われる | `webglcontextlost` イベントを処理し、`webglcontextrestored` 時に状態を復元する |
